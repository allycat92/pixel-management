# 은빛 늑대 길드 (Pixel Mercenary Guild)

도트 그래픽 기반 판타지 **길드 운영 매니지먼트** 게임입니다.
플레이어는 용병 길드의 운영자로서 여러 용병단을 거느리고, 대륙의 세력들 사이에서 의뢰를 골라 맡으며 길드의 이름을 높입니다.
빌드 도구나 외부 라이브러리 없이 HTML/CSS/JavaScript만으로 동작하며, 모든 캐릭터·몬스터·지도는 코드로 픽셀을 찍어 생성합니다.

설계 문서: [`docs/DESIGN.md`](docs/DESIGN.md)

## 실행 방법

```bash
# 저장소 루트에서 아무 정적 서버나 실행
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 게임 소개

### 길드와 용병단
- **운영 주체는 길드, 관리·파견 단위는 용병단**입니다.
- **직속 용병단**: 길드가 창설해 단원을 배속합니다. 단장(레벨만큼 전투력 보정), 결속도(함께 싸울수록 상승), 전적이 쌓입니다. 병영을 증축하면 더 많이, 더 크게 꾸릴 수 있습니다.
- **외부 계약 용병단**: 모집소의 용병단 시장에서 4주 단위로 계약합니다. 계약금·유지비 외에 보상 몫을 떼어 가고, 성향(돈 우선 / 명예 / 세력 동조)에 따라 특정 의뢰를 거부합니다. 충성도가 낮으면 재계약을 거부하거나 결전 도중 배신하기도 합니다.
- **단원 개인**: 직업 5종과 상급 직업 10종(전직), 스킬, 장비, 피로·사기, 전우/불화 관계가 있습니다.

### 세력 분쟁
- 6개 세력: 아스트라 왕국, 북부 귀족 연합, 자유 도시 연맹, 성광 교단, 은빛 숲 엘프, 붉은 모래 부족 연합.
- **금화는 전쟁에서**: 전쟁 의뢰는 보수가 크고, 괴물·치안 의뢰는 명성과 경험치 위주입니다.
- **평판**: 한 세력의 의뢰로 다른 세력을 치면, 의뢰주의 평판은 오르고 대상 세력(과 그 동맹)의 평판은 떨어집니다. 깊이 떨어진 평판은 잘 오르지 않고, 높은 평판은 쉽게 깎이며 매주 식습니다. 길드 등급이 높을수록 평판 하락이 줄어듭니다.
- **평판 혜택**: 45 신뢰(세력 혜택 + 장비 대여), 60(매주 세력 정예 용병), 75 맹우(최상급 장비 대여). 평판이 떨어지면 대여 장비는 회수되고 정예 용병은 소환됩니다. -40 이하면 의뢰가 끊기고, -60 이하면 첩자와 자객이 보복합니다.
- **영토**: 13개 지방마다 소유 세력과 장악도가 있습니다. 습격·공성·공작으로 장악도를 깎으면, 전쟁 중일 때 지방이 넘어갑니다.
- **세계는 스스로 움직입니다**: 전선 압박, 국경 분쟁, 선전포고와 강화가 길드와 상관없이 일어납니다.
- **대규모 결전**: 전쟁 중인 두 세력이 동시에 용병을 모집합니다. 한쪽 진영을 골라 용병단 2~3개를 함께 보내야 하며, 결과에 따라 지방의 주인이 바뀝니다. 아무도 맡지 않으면 국력대로 결판납니다.
- 의뢰 종류: 괴물 토벌·호위·탐사·마법 조사·방어 / 습격·거점 공략·공작·구출·방첩·방어전 / 사절 호위 / 결전.

### 이야기
- **특별 용병 7명**이 각자의 세력 분쟁 사연을 안고 모집소에 찾아옵니다. 함께 의뢰를 완수해 인연을 쌓으면 개인 의뢰가 열리고, 일부 장에서는 **선택**에 따라 세력 평판과 관계, 전쟁의 향방이 바뀝니다.
- **재앙급 괴물 6종**: 지방 의뢰를 충분히 해결하면 나타나며, 쓰러뜨리면 그 지방 세력의 평판이 크게 오릅니다.

조작: `다음 날 ▶` 버튼(또는 스페이스바)으로 하루를 넘깁니다. 진행은 매일 브라우저(localStorage)에 자동 저장됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/data.js` | 직업·특성·전직, 의뢰 유형, 시설, 랭크, 무작위 사건 |
| `js/world.js` | 세력, 지방(영토), 인접 관계, 용병단 이름·성향 |
| `js/content.js` | 몬스터, 재앙급 괴물, 장비, 특별 용병과 이야기 |
| `js/sprites.js` | 캐릭터·몬스터·아이콘·장비·깃발 도트 스프라이트 생성기 |
| `js/game.js` | 상태·저장, 길드 등급·시설, 단원·장비·상점, 하루 진행 |
| `js/company.js` | 직속 용병단과 외부 계약 용병단 |
| `js/faction.js` | 평판, 세력 관계, 영토, 전쟁, 세계 진행 |
| `js/contract.js` | 의뢰 생성·파견·판정, 세력 영향, 결전, 이야기, 보스 |
| `js/scene.js` | 상단 길드 홀 애니메이션 |
| `js/battle.js` | 전투 연출 (괴물·세력 병사, 여러 용병단) |
| `js/map.js` | 세력 영토 지도 |
| `js/ui.js`, `js/ui-tabs.js` | 공통 UI·대화·보고서 / 각 탭 화면 |

새 세력·지방은 `js/world.js`, 새 몬스터·장비·특별 용병은 `js/content.js`, 새 의뢰 유형은 `js/data.js`(+ `js/contract.js`의 `CONTRACT_EFFECTS`)에 항목을 추가해 늘릴 수 있습니다.
