# 은빛 늑대 길드 (Pixel Mercenary Guild)

도트 그래픽 기반 판타지 **길드 운영 매니지먼트** 게임입니다.
플레이어는 용병 길드의 운영자로서 여러 용병단을 거느리고, 대륙의 세력들 사이에서 의뢰를 골라 맡으며 길드의 이름을 높입니다.
빌드 도구나 외부 라이브러리 없이 HTML/CSS/JavaScript만으로 동작하며, 모든 캐릭터·몬스터·지도는 코드로 픽셀을 찍어 생성합니다.

설계 문서: [`docs/DESIGN.md`](docs/DESIGN.md)

## 실행 방법

```bash
# 저장소 루트에서 아무 정적 서버나 실행
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 게임 소개

### 길드와 용병단
- **운영 주체는 길드, 관리·파견 단위는 용병단**입니다.
- **직속 용병단**: 길드가 창설하고 용병대장 1명과 대원들을 배속합니다. 결속도(함께 싸울수록 상승)와 전적이 쌓입니다. 병영을 증축하면 더 많이, 더 크게 꾸릴 수 있습니다.
- **외부 계약 용병단**: 모집소의 용병단 시장에서 4주 단위로 계약합니다. 계약금·유지비 외에 보상 몫을 떼어 가고, 성향(돈 우선 / 명예 / 세력 동조)에 따라 특정 의뢰를 거부합니다. 충성도가 낮으면 재계약을 거부하거나 결전 도중 배신하기도 합니다.
- **용병대장**: 고유 직업, 높은 성장률(상한 Lv.40), 자기 용병단 전체를 강화하는 **지휘 스킬**을 가진 단 한 명뿐인 인물입니다.
  - 게임을 시작할 때 후보 9명 중 한 명을 고릅니다. 고르지 않은 8명은 다시 만날 수 없습니다.
  - 이후 길드 등급 E·C·B·A마다 대장 6명씩의 **영입 과제**가 공개됩니다. 조건을 한순간에 모두 만족하면 그 대장이 찾아오고, 영입 의뢰(서사)를 완수하면 합류합니다.
  - 과제끼리 서로 부딪힙니다: 안전한 연승 vs 도박 같은 의뢰, 교단 편 vs 이종족 편, 소수 정예 vs 대군, 금화 비축 vs 투자, 기한 안의 속도. 효율적이거나 과감하게 플레이하면 여러 대장을 얻을 수 있습니다. 기한을 넘기거나 조건이 불가능해지면 그 대장은 떠납니다.
- **특별 용병**: 고유 직업을 가진 대원으로, 아무 용병단에나 들어갑니다. 영입하면 이야기가 시작되고, 장을 마칠수록 레벨 상한·성장률·고유 스킬이 올라 대장 못지않게 강해집니다.
- **용병 대원**: 개인 능력치 편차가 없는 범용 용병입니다.
  - 직업을 골라 신병이나 숙련병으로 뽑습니다.
  - **승급 3단계**(기본 Lv.10 → 상급 Lv.20 → 최상급 Lv.30 상한)로 역할을 정합니다. 승급할 때마다 두 갈래 중 하나를 고릅니다(기본 5 → 상급 10 → 최상급 20).
- **용병단 = 대장 1명 + 대원 4~8명**(병영 단계에 따라).
- **스킬**: 고유 직업(대장·특별 용병)은 액티브 2개(기본기 + 특기)와 패시브 1개, 범용 대원은 현재 직업의 액티브 1개를 가집니다.
  - 기본기는 일반 공격에 해당합니다. 치유형은 공격 대신 치유합니다.
  - 특기는 범위 공격, 돌진, 기절, 아군 강화 같은 기술이며, 실시간 전투에서 실제로 쓰입니다.
- 공통으로 장비, 피로·사기, 전우/불화 관계가 있습니다.

### 세력 분쟁
- 6개 세력: 아스트라 왕국, 북부 귀족 연합, 자유 도시 연맹, 성광 교단, 은빛 숲 엘프, 붉은 모래 부족 연합.
- **금화는 전쟁에서**: 전쟁 의뢰는 보수가 크고, 괴물·치안 의뢰는 명성과 경험치 위주입니다.
- **평판**: 한 세력의 의뢰로 다른 세력을 치면, 의뢰주의 평판은 오르고 대상 세력(과 그 동맹)의 평판은 떨어집니다. 깊이 떨어진 평판은 잘 오르지 않고, 높은 평판은 쉽게 깎이며 매주 식습니다. 길드 등급이 높을수록 평판 하락이 줄어듭니다.
- **평판 혜택**: 45 신뢰(세력 혜택 + 장비 대여), 60(매주 세력 정예 용병), 75 맹우(최상급 장비 대여). 평판이 떨어지면 대여 장비는 회수되고 정예 용병은 소환됩니다. -40 이하면 의뢰가 끊기고, -60 이하면 첩자와 자객이 보복합니다.
- **영토**: 13개 지방마다 소유 세력과 장악도가 있습니다. 습격·공성·공작으로 장악도를 깎으면, 전쟁 중일 때 지방이 넘어갑니다.
- **세계는 스스로 움직입니다**: 전선 압박, 국경 분쟁, 선전포고와 강화가 길드와 상관없이 일어납니다.
- **패권국과 재앙**: 왕국과 교단은 대륙의 패권국으로, 각자 고대의 재앙을 봉인하고 있습니다. 플레이어가 손 놓고 있으면 북부와 엘프는 패권국에 먹히고, 자유 도시와 부족 연합 중 한쪽이 무너집니다. 패권국이 무너지거나 세력이 셋 멸망하면 **마물 군단(고룡 이그니스)** 또는 **마왕군(마왕 베르녹스)**이 대두해 대륙 전체와 전쟁을 벌이고, 최종 결전에서 그 수장을 쓰러뜨려야 합니다. 재앙이 지방 9곳을 차지하면 암흑시대로 게임 오버입니다.
- **세력 행동강령**: 왕국은 북부 귀족을 적극적으로 치고, 교단은 이종족(엘프·부족)을 향해 원정 성전을 벌이며, 엘프는 먼저 전쟁을 걸지 않고 숲에서 버팁니다. 자유 도시는 전쟁을 꺼리고 강화를 서두르며, 부족 연합은 노예 상인과 성전군을 증오합니다.
- **대규모 결전**: 전쟁 중인 두 세력이 동시에 용병을 모집합니다. 한쪽 진영을 골라 용병단 2~3개를 함께 보내야 하며, 결과에 따라 지방의 주인이 바뀝니다. 아무도 맡지 않으면 국력대로 결판납니다.
- 의뢰 종류: 괴물 토벌·호위·탐사·마법 조사·방어 / 습격·거점 공략·공작·구출·방첩·방어전 / 사절 호위 / 결전.

### 전투
- 용병대장 1명과 대원 3~8명으로 이루어진 부대 6~10개가 한 화면에서 **실시간으로 스스로 싸웁니다**. 아군은 파견한 용병단과 의뢰주 세력의 지원 부대, 적은 대상 세력의 병사나 괴물 무리입니다.
- 근접 직업은 파고들고, 원거리 직업은 거리를 두며, 성직자는 치유합니다. 대장을 잃거나 병력이 크게 꺾인 부대는 패주하고, 충성도가 바닥난 외부 용병단은 전투 도중 배신합니다.
- 아래 현황판에서 부대별 남은 병력을 볼 수 있고, 속도(×1/×2/×4)를 바꾸거나 바로 결과로 넘어갈 수 있습니다.
- 재앙이 대두한 뒤로는 의뢰 난이도 상한이 ★10에서 ★14로 열립니다.

### 이야기
- **용병대장 33명**에게는 각자 영입 서사가 있고, **특별 용병 7명**은 각자의 세력 분쟁 사연을 안고 모집소에 찾아옵니다. 함께 의뢰를 완수해 인연을 쌓으면 개인 의뢰가 열리고, 일부 장에서는 **선택**에 따라 세력 평판과 관계, 전쟁의 향방이 바뀝니다.
- **재앙급 괴물 6종**: 지방 의뢰를 충분히 해결하면 나타나며, 쓰러뜨리면 그 지방 세력의 평판이 크게 오릅니다.

조작: `다음 날 ▶` 버튼(또는 스페이스바)으로 하루를 넘깁니다. 진행은 매일 브라우저(localStorage)에 자동 저장됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/data.js` | 직업 기본치, 특성, 의뢰 유형, 시설, 랭크, 무작위 사건 |
| `js/classes.js` | 스킬 정의·설명 생성, 대원 직업 계통(35), 용병대장 고유 직업(33), 특별 용병 고유 직업(7) |
| `js/world.js` | 세력, 지방(영토), 인접 관계, 용병단 이름·성향 |
| `js/content.js` | 몬스터, 재앙급 괴물, 장비, 특별 용병과 이야기 |
| `js/sprites.js` | 캐릭터·몬스터·아이콘·장비·깃발 도트 스프라이트 생성기 |
| `js/game.js` | 상태·저장, 길드 등급·시설, 단원·장비·상점, 하루 진행 |
| `js/company.js` | 직속 용병단과 외부 계약 용병단 |
| `js/faction.js` | 평판, 세력 관계, 영토, 전쟁, 세계 진행 |
| `js/contract.js` | 의뢰 생성·파견·판정, 세력 영향, 결전, 이야기, 보스 |
| `js/captains.js` | 용병대장 영입: 창설 선택, 영입 과제, 영입 의뢰 |
| `js/art.js` | 외부 일러스트 불러오기 (`assets/art/manifest.json`, 없으면 도트로 대체) |
| `js/scene.js` | 상단 길드 홀 애니메이션 |
| `js/battle.js` | 실시간 집단 전투 (부대 편성, 자율 AI, 시뮬레이션·재생) |
| `js/map.js` | 세력 영토 지도 |
| `js/ui.js`, `js/ui-tabs.js` | 공통 UI·대화·보고서 / 각 탭 화면 |

새 세력·지방은 `js/world.js`, 새 몬스터·장비·특별 용병은 `js/content.js`, 새 의뢰 유형은 `js/data.js`(+ `js/contract.js`의 `CONTRACT_EFFECTS`)에 항목을 추가해 늘릴 수 있습니다.

## 그림 작업 (일러스트)
외부 이미지 생성 도구(ChatGPT 등)와 GitHub로 그림을 주고받습니다. 절차는 [`art/README.md`](art/README.md), 화풍 기준은 [`art/STYLE.md`](art/STYLE.md)입니다.
- 요청서 생성: `node tools/art/requests.js` → `art/requests/phase1.md` (게임 데이터에서 자동 생성)
- 납품: `art/inbox/`에 요청서의 파일 이름으로 PNG 저장
- 후처리: `python3 tools/art/process.py` → `assets/art/` + `manifest.json` (Pillow 필요)
- 게임은 등록된 그림만 쓰고, 없는 그림은 기존 도트로 대신합니다.
