# 은빛 늑대 용병단 (Pixel Mercenary Guild)

도트 그래픽 기반 판타지 **용병단 운영 매니지먼트** 게임 프로토타입입니다.
빌드 도구나 외부 라이브러리 없이 HTML/CSS/JavaScript만으로 동작하며, 모든 캐릭터와 배경은 코드로 픽셀을 찍어 생성합니다.

## 실행 방법

```bash
# 저장소 루트에서 아무 정적 서버나 실행
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 직접 열어도 대부분 동작하지만, 폰트 로딩 때문에 로컬 서버 사용을 권장합니다.

## 게임 소개

- **용병 고용** – 주점에서 전사·궁수·마법사·성직자·도적 지원자를 고용합니다. 각 용병은 무작위 외형, 능력치(힘/민첩/지력/체력), 특성(용맹, 겁쟁이, 천재, 탐욕 등)을 가집니다.
- **특별 용병과 이야기** – 랭크가 오르면 고유한 사연을 가진 특별 용병 5명(카이, 세라핀, 리라, 그롬, 아스텔)이 주점에 찾아옵니다. 함께 의뢰를 완수해 인연을 쌓으면 개인 의뢰가 열리고, 대화와 함께 전설 장비·칭호를 얻습니다.
- **의뢰 파견** – 토벌/호위/탐사/마법 조사 의뢰마다 중시하는 능력치가 다릅니다. 파티를 꾸리면 예상 성공률이 표시됩니다.
- **전투 연출** – 의뢰 결과는 지역 배경 위에서 단원과 몬스터가 싸우는 도트 애니메이션으로 보여줍니다. 몬스터는 15종(고블린, 늑대, 거미, 트롤, 망령, 와이번 등)입니다. 메뉴에서 끌 수 있습니다.
- **결과** – 대성공·성공·실패·대실패. 실패하면 부상, 대실패하면 단원이 전사할 수도 있습니다. 성직자를 데려가면 위험이 줄어듭니다.
- **대륙 지도** – 왕도 평원에서 시작해 은빛 숲, 안개 늪지, 사막 교역로, 서리 협곡, 용의 등뼈 산맥으로 활동 영역을 넓힙니다. 지역마다 출몰 몬스터와 난이도가 다르고, 전초기지를 세우면 의뢰가 늘고 이동이 빨라집니다.
- **장비와 상점** – 무기·방어구·장신구를 5개 등급(낡은 → 강철 → 미스릴 → 룬 → 전설)으로 사고팔고 장착합니다. 약초로 부상을 바로 치료할 수 있습니다.
- **경영** – 7일마다 주급을 지급합니다. 금화가 모자라면 단원이 떠나고, 빚이 -200을 넘으면 파산합니다.
- **시설** – 숙소, 훈련장, 의무실, 주점, 의뢰 게시판, 대장간을 증축해 용병단을 키웁니다.
- **목표** – 명성을 쌓아 F → S랭크 달성!

조작: `다음 날 ▶` 버튼(또는 스페이스바)으로 하루를 넘깁니다. 진행은 매일 브라우저(localStorage)에 자동 저장됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/data.js` | 직업, 특성, 의뢰 유형, 시설, 랭크, 무작위 이벤트 데이터 |
| `js/content.js` | 지역, 몬스터, 장비, 특별 용병과 이야기 데이터 |
| `js/sprites.js` | 캐릭터·몬스터·아이콘·장비 도트 스프라이트 생성기 |
| `js/game.js` | 게임 상태와 규칙 (고용, 파견, 판정, 장비, 이야기, 주급, 저장) |
| `js/scene.js` | 상단 길드 홀 애니메이션 장면 (캔버스) |
| `js/battle.js` | 의뢰 결과 전투 연출 |
| `js/map.js` | 대륙 지도 |
| `js/ui.js` | 탭 화면, 모달, 대화창, 입력 처리 |
| `css/style.css` | 픽셀 스타일 UI |

새 직업·의뢰·이벤트는 `js/data.js`, 새 지역·몬스터·장비·특별 용병은 `js/content.js`에 항목을 추가하는 것만으로 늘릴 수 있습니다.
