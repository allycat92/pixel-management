# Q5 — 전투가 결과를 정하는 모드 실전 점검 (GPT-QA) — 예고

**3단계가 게임 브랜치에 합쳐지면 총괄이 READY 로 바꾼다.** 그 전에는 시작하지 않는다.
켜는 법, 예상 단어, 손실 완충 등 자세한 것은 그때 `docs/plans/battle_stats/stage3_notes.md` 를 보고 이 문서에 채운다.

## 미리 알려 둘 범위
- `Game.RESOLVE='battle'` 로 켠다. 출정 창에 뜨는 다섯 단어 예상과 실제 결과가 맞아떨어지는지 본다.
- 관전하는 전투가 실제로 결과를 정한 그 전투인지 확인한다.
- 지는 경우에도 회복할 수 있는지 본다(손실 완충).
- 특별 전투가 아닌 곳에서 단원이 죽지 않는지 확인한다.
- 화면 폭 두 가지(1280·400)에서 본다.
