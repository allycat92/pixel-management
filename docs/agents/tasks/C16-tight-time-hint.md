- 재현: 시드 582702 150일, 발렌 거점 공략 #721, 2명, R 1.139.

## Do (전투 모드에서만, roll 화면 그대로)
1. 출정 창(편성 후 예상)에서 `Stats.killTime` 이 시간 제한의 일정 비율을 넘으면, 예상 단어 아래에 짧은 이유를 한 줄 붙인다.
   - 예: 「시간이 빠듯함 — 90초 안에 다 쓰러뜨리지 못할 수 있음」
   - 기준 비율은 `Stats.KN` 의 시간 보정 값(`BM_TIME_EDGE`·`BM_TIME_TAU`)에서 정한다. 승률이 눈에 띄게 깎이는 지점(예: killTime 30초 이상, 시간 안에 끝낼 확률 ≤ 0.9)에서 시작한다.
   - 기준 비율은 상수로 따로 두지 말고 `Stats` 에 작은 함수(예: `Stats.timeRisk(spec)`)를 두어 쓴다.
   - %·숫자는 보이지 않는다. 예상은 단어로만 보여 준다는 주인 결정이 있다.
2. 의뢰 카드에는 붙이지 않는다(카드는 단어만). 결전 카드처럼 다부대 의뢰도 편성한 뒤에만 보인다.
3. 판정·예상 단어·`Stats.KN` 값은 바꾸지 않는다. 표시만 한다.
4. 시험
   - `node --check`, `node tools/sim/battle.js 100` 은 miss=0 이어야 한다.
   - roll md5 는 그대로여야 한다. 지금 기준은 게임 브랜치 최신에서 다시 잰다.
   - 전투 모드 봇 요약은 바이트 단위로 같아야 한다.
   - 위 재현 저장의 400·1280 에서 줄이 뜨는지 캡처한다. 시간이 넉넉한 전투에서는 뜨지 않는지도 캡처한다.
   - 봇 표본에서 이 줄이 뜨는 비율과, 뜬 전투의 시간 초과 패배 비율, 안 뜬 전투의 시간 초과 패배 비율을 적는다.
