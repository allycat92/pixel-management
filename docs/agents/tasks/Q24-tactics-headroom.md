# Q24 — 작전 여지 측정 (GPT-QA, 측정만)

**왜:** 주인 결정은 「작전(전술)이 효과의 30~50%를 정한다」인데, 지금 전투 모드에서 플레이어가 바꿀 수 있는 것은 「누구를 보내나」뿐이고 작전은 0%다(클라우드 측정 11-28). 2단계(역할별 자리)·5단계(작전 보너스, `docs/plans/battle_stats/design.md` §8.3, Stage 2 §543~)를 만들기 전에, 같은 전력에서 **배치·조합만 바꾸면 결과가 얼마나 움직이는지** 숫자로 알아야 한다.

## 할 일 (게임 코드는 고치지 않는다 — 측정 스크립트는 `tools/sim/q24_*.js` 로 새로 만들어도 된다)
- `tools/sim/battle.js`·`collect-calibration.js` 의 방식으로, 같은 의뢰·같은 단원 묶음에 대해 다음을 바꿔 전투(`Battle.run`, 전투 모드 spec)를 각 200판 이상 돌린다:
  1. 지금 자리(대장 먼저, 레벨 순) vs 근접 앞·원거리/치유 뒤 vs 반대(일부러 나쁜 자리).
  2. 같은 인원·비슷한 레벨에서 조합만 다른 부대(근접 3 / 근접 2+원거리 1 / 근접 1+치유 1+원거리 1 …).
  3. 대장 방식(근접·원거리·격려)별.
- 각각 승률·평균 전투 시간·쓰러진 수를 「백중」「우세」 띠 의뢰에서 따로 낸다.
- 결론: 자리만으로 승률이 몇 %p 움직이나, 조합으로는 몇 %p 인가 — 「30~50%」 목표와 비교해 2단계·5단계에 필요한 크기를 한 문단으로.
