# Q28 — 3D 마네킹으로 그린 달리기 6명 실제 전투 확인 (GPT-QA, 화면만)

등록된 것: 바렌(`sheet/captain/blademaster`), 이사벨(tactician), 키아라(huntress), 진(fixer), 하랄드(veteran), 카이(`sheet/hero/kai`) — 모두 3D 안내 그림 위에 GPT 가 그린 달리기(주인: 바렌 「훌륭해」, 나머지 「초안 단계 통과」).

## 할 일 (게임 코드·그림 수정 없음)
- `python3 tools/serve.py` 로 띄우고, 6명이 실제로 뛰는 전투를 만든다(새 게임 첫 대장 선택, 영입, 이야기 의뢰 등 — 필요하면 저장을 시험용으로 꾸며도 됨, 방법을 적을 것). 1배·4배로 끝까지 관전.
- 확인: 달리기 칸이 실제로 그려지는가(코드 그림 대체 없음), 발 미끄러짐(디딘 발이 땅에서 미끄러지는 px — Q12/Q15 방식), 대기↔달리기↔공격 전환에서 몸 크기·위치가 튀지 않는가, 세력 색 칠하기(직업 시트 아님 — 대장·영웅은 색 그대로인지), 원거리 물러서기(엔진 VER 2) 때 달리기 칸이 쓰이는가.
- 각 캐릭터 1배 장면 캡처 1장 + 문제 칸 확대.
- 그림의 좋고 나쁨은 판단하지 말고 사실만(주인이 판단한다).
