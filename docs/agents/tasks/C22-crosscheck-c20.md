# C22 — GPT 의 C20 교차 확인 (Codex, 보고만)

## Why
GPT 가 C20 을 했다(`11e1ad5`, agent/gpt-qa). 내용은 두 가지다.
- 전투 모드 결전 배신을 출격 때 고정한다.
- roll 외부단 손실을 `resultRoll` 로 굳힌다.

전투 모드 봇 요약은 전후 바이트 단위로 같았다. 그런데 **roll 기본 봇(시드 1~12) 365일 금화가 40,852 → 23,781** 로 크게 내렸다.
- 추가 묶음 601·701 은 53.2k → 39.0k, 61.9k → 61.0k 다. 세 묶음 모두 같은 방향이다.
- 외부 손실 합계도 29→31, **25→44** 로 늘었다.

GPT 는 「확률은 같고 갈래만 달라졌다」고 본다. 클라우드는 **상관(correlation)** 을 의심한다.
- `resultRoll` 이 같은 임무 난수열에서 판정 굴림 다음 값을 쓴다면, 실패·대실패가 나온 난수열에서는 손실 굴림도 한쪽으로 치우칠 수 있다.
- C14 초안에서 Codex 가 본 것과 같은 문제다.

## Do
1. C20 코드(`git show 11e1ad5 -- js/`)를 읽는다. roll 손실 굴림이 판정 굴림과 **같은 난수열의 연속 값**을 쓰는지 본다. 그렇다면 그 상관을 수치로 보인다.
   - 예: 실패한 임무에서 손실 굴림값 분포, 기대 손실률 vs 실제
2. roll 봇을 시드 세트 3개(1·601·701, 각 12판×365일)로 전후 비교한다. 외부단 손실 횟수를 **실패·대실패 횟수당**으로 나눠 기대값과 비교한다.
3. 전투 모드 배신 고정을 확인한다.
   - 저장 시드 규칙이 맞는가
   - 공유 소비가 맞는가
   - 옛 저장 처리가 맞는가
   - 관전과 판정이 같은가
4. 고칠 안을 제안한다(코드는 고치지 않는다). 예: 손실 굴림에 다른 소금을 쓰는 별도 난수열.
