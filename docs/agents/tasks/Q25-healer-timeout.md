# Q25 — 치유 대장·치유 대원 편성의 시간 초과 (GPT-QA, 측정만)

**왜:** Q24 에서 야전 의무관 대장 + 근접·치유·궁수 대원이 「우세」에서 11/236(4.7%) 90초 시간 초과로 졌다. 「우세」는 85~90% 이겨야 하는데, 이기고 있던 싸움을 시간으로 지는 것은 플레이어가 납득하기 어렵다.

## 할 일 (게임 코드 수정 없음, 측정 스크립트는 `tools/sim/q25_*.js`)
- Q24 의 표본(`docs/agents/reports/data/Q24/paired-offers.jsonl.gz` 의 spec)을 다시 써서, 치유가 두 명(대장 의무관/성자·순례 기사 같은 치유 대장 + 치유 대원) 이상인 편성의 시간 초과 비율을 백중·우세·압도 띠별로 낸다. 치유 대장 전부(`js/captains.js` 에서 치유 액티브를 가진 대장)를 각각.
- 시간 초과 판의 공통점: 적 종류(괴물/병사, 보스), 적 체력 총량 대비 우리 피해 속도, 치유가 받은 피해를 얼마나 되돌렸는지, 마지막 30초에 남은 적 수.
- 예상(`Stats.timeRisk`, `killTime`)이 이 판들을 「시간이 빠듯함」으로 미리 잡았는지(잡은 비율).
- 결론 한 문단: 예상 쪽(시간 위험 경고)을 고칠 일인지, 전투 쪽(치유 편성의 공격력 부족)인지.
