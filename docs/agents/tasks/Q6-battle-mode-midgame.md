# Q6 — 보상 조정 뒤 전투 모드 60~200일 점검 (GPT-QA)

**보상 조정이 들어갔다.** 내용은 `docs/plans/battle_stats/stage3_notes.md` 「Mid-game economy」 절에 있다.
- 전투 모드에서 59~121일에 만들어진 마감 있는 의뢰가 더 받는다. 가장 높을 때 금화 ×1.25, 명성 ×3.25 다.
- 오를 때와 내릴 때는 사다리꼴로 천천히 바뀐다.
- 마감 없는 이야기·보스·최종전 의뢰는 그대로다.
- 봇 측정에서 S 등급은 95~108일에 온다.

이번에는 **60~200일**을 본다. 특히 다음을 확인한다.
- 카드의 보수·명성이 실제로 받는 값과 같은지
- 110~121일에 명성이 눈에 띄게 줄어드는 게 어색하지 않은지
