# Q8 — 전투 모드 후반·최종전 점검 (GPT-QA)

## Why
Q5 는 1~100일을 봤다. 전투 판정 모드를 기본값으로 바꾸기(4단계) 전에 후반도 봐야 한다.
- 200~365일 구간, 재앙(마왕·고룡) 출현과 토벌, 최종 결전, 이야기 절정의 전투 판정과 사망 규칙을 실제로 본 사람이 아직 없다.
- 60~120일 보상 조정은 지금 진행 중이다. 이 점검의 후반 보상과는 겹치지 않는다.

## Do (`?resolve=battle`, 1280×900 과 400×800, 새 프로필)
1. 각 폭에서 200일 근처까지 빠르게 간다.
   - 게임 API 보조 플레이로 가도 된다(Q5 와 같은 방식, 의뢰 배정 등). 단 판정·저장은 실제 경로를 쓴다.
   - 그 뒤 200~365일은 실제 화면으로 진행한다.
2. 확인할 것
   - **재앙**: 출현, 진행(암흑기 경고), 토벌 의뢰의 예상 단어와 결과, 토벌 뒤 결말 화면
   - **최종 결전**: 예상 단어(「요구 전투력」 같은 옛 표시는 C12 대상이니 목록만 적는다), 다부대 출격, 결과, 결말
   - **사망**: 보스·최종전·이야기 마지막 장에서 대실패할 때만 죽는지, 대장은 죽지 않는지, 한 부대에서 최대 1명인지, 길드 인원이 3명 이하일 때 막히는지. 양성 사례가 안 나오면 격리 시험 저장으로 확인한다.
   - **의뢰판 폭**: 후반에 어려운 의뢰가 사라지는지. 10일마다 기록한다.
   - **예상 단어의 정확도**: 이야기·보스 의뢰가 낙관 쪽으로 치우치는지(측정상 「우세」가 74~82% 이긴다). 표본을 적는다.
   - **진행감**: 할 일이 없어지는 구간이 있는지, 돈이 쌓이기만 하는지.
3. Q5 처럼 결함 표(심각도 순)와 표본 표를 만든다.
