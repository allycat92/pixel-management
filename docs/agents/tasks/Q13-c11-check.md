# Q13 — C11 화면 수정과 즉시 저장 교차 확인 (GPT-QA)

## Why
Codex 가 C11 에서 Q4 결함 6건과 Q5 제목 줄바꿈을 고쳤다(`7753768` 합침). 또 관리 조작을 하면 바로 저장하도록 바꿨다(`Game.saveManagement`).
- 결함을 찾은 쪽(GPT)이 직접 다시 본다.
- 즉시 저장이 새로고침으로 결과를 다시 뽑는 꼼수를 열지 않는지 확인한다.

## Do (1280×900·400×800, roll 과 `?resolve=battle` 둘 다)
1. Q4-01~06 과 Q5 제목을 Q4 와 같은 순서로 다시 재현한다. 고쳐졌는지 PASS / FIX 로 적는다.
   - Codex 캡처는 `docs/agents/reports/shots/C11/` 에 있다.
2. 즉시 저장 항목마다 조작한 뒤 새로고침해서 남는지 본다.
   - 항목: 증축, 구매, 장착·해제, 고용·해고, 배속, 이름 변경, 약초, 승급
3. **꼼수 확인**
   - (a) 의뢰를 출격시킨 같은 날 관리 조작(예: 장착)을 하고 새로고침한다.
     - 출격 상태가 남는가?
     - 출격이 사라져 다시 고를 수 있다면 그 자체는 괜찮다. 출격 전 상태로 돌아가는 것뿐이다.
     - 그다음 「다음 날」로 귀환시키고 결과를 적는다. 같은 출격을 다시 하면 결과가 달라지는지 본다.
   - (b) 귀환 결과가 나온 뒤 보고서를 보기 전에 새로고침해서 결과가 바뀌는지 본다.
   - (c) 승급·구매 직후 새로고침과 이어지는 다음 날 처리가 같은 결과를 내는지 본다.
   - 결과가 바뀌는 경로가 있으면 P1 로 적는다. 재현 순서와 시드를 함께 적는다.
4. 콘솔 오류, 넘침, 키보드 순서(Tab)도 함께 본다.
