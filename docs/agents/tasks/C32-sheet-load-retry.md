# C32 — 시트 PNG 받기 실패 뒤 다시 받기 (GPT, 작은 고침)

Q29 「동시부하 예외」: 한 서버에 헤드리스 브라우저 10개를 동시에 띄웠더니, 로드릭이 ×4 관전 내내 원본 대신 코드 도트로 나왔다.

## 지금 코드 (`js/art.js`)
- `Art.sheet()` 는 매 프레임 그림 상태를 다시 본다. 그래서 **늦게 도착한** 그림은 도착하는 순간부터 쓰인다.
- 하지만 **받기에 실패한** 그림(`complete && naturalWidth === 0`)은 다시 받지 않는다.
  그러면 새로 고칠 때까지 그 시트는 계속 코드 도트로 나온다(추정).
  느린 회선이나 순간 끊김에서도 같은 일이 생길 수 있다.

## 할 일
1. Q29의 동시부하 장면을 재현한다. 그때 로드릭 시트 `images[id]` 의 상태를 적는다: `complete`, `naturalWidth`, onerror 여부.
   - 추정이 틀렸으면(실패가 아니라 다른 원인) 고치지 말고 원인만 보고한다.
2. 실패였다면 `js/art.js` 에 다음을 넣는다.
   - 다시 받기는 그림당 최대 2번이다. 간격은 1초, 그다음 3초를 둔다.
   - 같은 주소에 `&r=<n>` 을 덧붙인다(캐시된 실패를 피하려고).
   - 다시 받는 동안 `sheetReadyState` 는 PENDING 이 아니다. 실패한 상태로 두어서 관전 시작(1.5초 기한)을 늦추지 않는다.
   - 도착하면 `sheetCache` 의 낡은 항목을 쓰지 않게 한다(새 `Image` 를 넣었다면 캐시를 지운다).
3. 다시 재현해서, 실패 뒤 도착하면 원본 시트로 바뀌는지 확인한다.
