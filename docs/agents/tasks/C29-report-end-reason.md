# C29 — 결과창 맨 위에 「왜 끝났나」 한 줄 + 관전의 「아군 후퇴」 (GPT, 표시만)

총괄이 GPT 에게 넘긴 C 일감(주인 11-28: 그래픽 논의 동안 시스템 개선·QA 는 GPT 에게). 이 일감에 한해 게임 코드를 고쳐도 된다.

**왜:** Q23 — 일반 실패의 종료 이유를 보고서만 보고는 알기 어렵고, 대실패의 「전멸」은 보수 줄에서야 나온다. 관전에서 후퇴로 끝나면 아군이 화면 밖으로 뛰어갈 뿐 아무 표시가 없다.

**할 일 (전투 모드 보고서만, roll 은 그대로):**
- `r.battle.end`(`js/battle.js` 1247 근처: `retreat`·`rout`·`wipe`·`time`, 승리 쪽 끝) 를 보고서 제목 아래 한 줄로: 예) 「아군이 전열을 잃고 물러났습니다」(retreat), 「아군이 모두 쓰러졌습니다」(아군 wipe), 「적을 모두 쓰러뜨렸습니다」/「적이 달아났습니다」(승리), 시간 초과는 지금 문구 유지. 주어를 분명히(「아군」「적」). 문구는 짧게.
- 관전(`js/battle.js` 표시 쪽)에서 후퇴가 시작될 때 화면에 「아군 후퇴」 한 번(기존 이벤트 글씨 방식, `st.events` 가 기록·해시에 들어가지 않는지 먼저 확인 — 들어가면 표시 쪽 상태에만 넣는다).
- 대실패 보수 줄의 「전멸」도 「아군 전멸」로.
