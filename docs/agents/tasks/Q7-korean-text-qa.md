# Q7 — 게임 속 한국어 글 다듬기 점검 (GPT-QA)

## Why
게임에는 대장·영웅 이야기, 의뢰 제목, 사건, 특성·직업 설명 같은 한국어 글이 많다. 이 글들은 여러 번에 걸쳐 쓰였다. 그래서 아래 같은 것들이 섞여 있을 수 있다.
- 오타와 조사 오류(을/를, 이/가, 와/과)
- 같은 인물·지명의 표기 차이
- 존댓말과 반말이 섞인 곳
- 설정과 어긋나는 문장

플레이어가 직접 읽는 글이라 화면 결함만큼 중요하다.

## Do
1. 아래 파일 안의 플레이어에게 보이는 한국어 문자열을 모두 읽는다.
   - `js/captains.js`, `js/content.js`, `js/data.js`, `js/classes.js`, `js/world.js`, `js/faction.js`, `js/contract.js`
   - `js/ui.js`, `js/ui-tabs.js` 의 화면 문구
2. 다음을 찾는다.
   - 맞춤법·띄어쓰기·조사 오류
   - 표기 불일치: 같은 사람·지역·세력 이름이 다르게 쓰인 곳. 목록을 만들어 대조한다.
   - 말투가 한 화면 안에서 섞이는 곳. 같은 인물의 말투가 장면마다 달라지는 곳.
   - 이야기 순서상 모순: 앞 장에서 죽은 인물이 다시 나오는 것, 관계가 바뀌는 것 등
   - 동적으로 붙는 조사가 틀리는 곳. 예: `${name}을` 처럼 이름 끝 받침에 따라 달라져야 하는데 고정된 곳. 게임에 받침 처리 함수가 있으면 그것을 쓰는지 본다.
   - 아직 남은 영어나 개발용 문구
3. 항목마다 다음을 적는다.
   - 파일:줄
   - 지금 글
   - 고친 글
   - 종류
4. 설정 모순처럼 판단이 필요한 것은 따로 모아 총괄에게 묻는다.

## Do not touch
파일 자체(보고만 한다. 고치는 일은 총괄이 확인한 뒤 Codex 가 한다).

## Deliver
- 브랜치 `agent/gpt-qa` 에 보고서 `## Q7 — <날짜>` 를 쓴다. 종류별 표와 이름 표기 대조표를 넣는다.
- 이 줄을 REVIEW 로 바꾼다.
