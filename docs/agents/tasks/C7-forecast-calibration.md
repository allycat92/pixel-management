# C7 — 예상 단계(압도·우세·백중·열세·무모)를 실제 승률에 맞추는 측정 (Codex)

## Why
주인 결정(11-27)은 네 가지다.
1. 출전 화면의 예상은 전술을 뺀 능력치만으로 다섯 단계를 보여 준다.
2. 「우세」에 평범한 용병단을 보내면 **85~90%** 이기고, 「백중」은 **반반**이다.
3. 적의 세기는 의뢰의 별 등급이 정한다. 쉬운 의뢰부터 벅찬 의뢰까지 넓게 나오고, 플레이어가 고른다.
4. 사망은 보스·최종 결전에서만 생긴다.

설계는 `docs/plans/battle_stats/`, 0~1단계 노트는 `stage01_notes.md`, 도구는 `tools/sim/shadow.js` 다(C6 에서 손질함).
측정 결과 지금 기본값에서는 R=1 이 약 90% 승리이고, 50% 지점이 적 종류마다 다르다(군인 ~0.95, 괴물 ~0.80).

## Measure (게임 코드와 기본값은 바꾸지 않는다 — `--set` / `--sweep` 만)
1. 기본값으로 `node tools/sim/shadow.js 12 365 --offers` 를 돌리고 다섯 표를 보고서에 붙인다.
   - 표: R 구간별 승률, 예상 단계별 승률·대성공, 날짜 구간, 적 종류(archetype), 의뢰 종류
2. 적 종류마다 승률 10/50/90% 가 되는 R 을 구한다. 로지스틱 맞춤 등 방법은 자유이고, 방법을 적는다.
   - 그 결과로, 다섯 단계 경계가 아래를 만족하게 하는 보정값 후보를 제안한다.
     - 「백중」의 중앙 = 50%
     - 「우세」 = 85~90%
     - 「압도」 ≥ 97%
     - 「열세」 ≈ 20~35%
     - 「무모」 < 10%
   - 보정값: `CAL_KIND` 같은 종류별 배율과 `BANDS` 경계.
   - 제안한 값을 `--set` 으로 넣어 다시 돌려 표로 확인한다.
3. **대성공** 비율을 단계별로 잰다. `GREAT_HP`·`GREAT_HEADS` 를 몇 값으로 훑어, 「우세」의 대성공이 약 25~35% 가 되는 값을 찾는다.
4. 날짜 구간별 별 등급 분포와 R 분포를 표로 낸다.
   - 지금 봇이 실제로 받는 의뢰가 얼마나 넓은 범위인지 보여 준다.
   - 클라우드가 「넓게 나오는 의뢰」 규칙을 설계할 자료다.
5. 전투 시간(중앙·p90)과 전멸 비율을 단계별로 낸다.
