# C23 — 둘째 부대 만들기 안내 (Codex)

## Why
GPT 의 Q19(`docs/agents/reports/gpt-qa.md` 「Q19」)는 전투 모드를 기본으로 해도 된다고 봤다. 다만 조건이 하나 붙었다. **둘째 부대를 만드는 법과, 만든 뒤 남길 급료**를 한 단계 더 안내하는 것이다.
- 같은 시드로 비교하면 차이가 크다. 직속 1부대는 120일에 B 등급이고, 둘째를 일찍 만들면 113일에 S 등급이다.
- 1일에 병영과 창설을 연달아 하면 450금이 30금으로 줄어, 첫 주급 76금도 남지 않는다.

## Do (전투 모드·roll 모두. 정보 표시만, 규칙은 바꾸지 않는다)
1. 용병단 창설 버튼·창에 한 줄을 넣는다: 「창설 뒤 남는 금화 N · 다음 정산(M일) 예상 급료 K」.
   - 남는 금화가 예상 급료보다 적으면 경고 색으로 보이게 한다.
   - 기존 함수 `Game.paydayTotal()`, `Game.nextPaydayDay()` 를 쓴다.
2. 빈 용병단(단원 0)에는 「예비 단원 배속」·「다른 부대에서 옮기기」 버튼을 바로 보여 준다(기존 배속 기능으로 연결한다).
   - 대장이 없어도 일반 단원 1명으로 첫 출격이 된다는 것도 한 줄로 알려 준다.
3. 「한 부대 다듬기」의 둘째 부대 안내 힌트와 문구를 맞춘다.
4. 시험
   - `node --check`, `node tools/sim/battle.js 100` 은 miss=0 이어야 한다.
   - roll md5 는 `docs/agents/README.md` 기준 그대로여야 한다(표시만이니까).
   - 400·1280 캡처를 남긴다.
