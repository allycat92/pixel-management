# C30 — 관전 시작 전에 시트 그림 미리 받기 (GPT, 표시만)

총괄이 GPT 에게 넘긴 C 일감. 이 일감에 한해 게임 코드를 고쳐도 된다.

**왜:** 새로고침 직후 관전을 열면 처음 7~12% 의 움직이는 칸이 옛 코드 그림으로 그려진다 — 시트 PNG 가 아직 안 받아져서. 그 구간이 바로 달리기 그림이 보일 짧은 돌진 구간이다(11-28 측정).

**할 일:** `Battle.play`(`js/battle.js` ~2773) 가 시작하기 전에 그 전투에 나오는 유닛들의 시트(`Art.sheetFor`)가 다 받아졌는지 기다린다(최대 1.5초, 넘으면 그냥 시작 — 지금처럼). 기다리는 동안 「준비 중」 같은 표시는 필요 없으면 생략. 이미 받은 그림은 기다리지 않는다. 결과·해시·난수 무관(표시만).

**검사:** C29 와 같은 시험 + 브라우저에서 새로고침 직후 관전의 첫 1초에 코드 그림 칸이 0 인지(11-28 측정 방식: `pose()` 를 감싸 칸 종류를 센다 — `docs/agents/reports` 에 방법을 적을 것). 보고: `gpt-qa.md` C30 절.
