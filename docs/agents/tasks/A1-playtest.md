# A1 — 플레이테스트 한 바퀴와 화면 검수 (GPT-QA — 2026-11-26 Antigravity 에서 옮김)

## Why
주인이 방향은 맞다고 했지만, 비어 있는 부분과 어색한 부분이 많다고 했다. 클라우드는 브라우저 화면을 오래 지켜볼 수 없으니
사람처럼 직접 해 보고 무엇이 이상한지 짚어 줄 눈이 필요하다.

## What to do
1. 저장소 루트에서 `python -m http.server 8000` 을 띄운다. 브라우저로 http://localhost:8000 을 연다.
2. **새 게임으로 30~40분 놀기**
   - 시작 대장 고르기 → 용병 모집 → 의뢰 몇 개 → 전투 재생(1배속과 4배속 각각 몇 번) → 며칠 넘기기 → 승급·대장 이야기 하나.
3. 보면서 다음을 적는다. 화면을 찍어 남긴다.
   - **오류**
     - 콘솔 오류
     - 멈춤
     - 버튼이 안 먹힘
     - 숫자가 이상함(음수·NaN·100% 넘음)
     - 저장·불러오기 뒤 달라지는 것
   - **전투 화면**
     - 유닛이 서 있는데 밀려 미끄러짐
     - 그림이 찌그러짐
     - 달리기가 어색함
       - 일반 전사·니클라는 그려 둔 달리기가 있다.
       - 나머지는 대기 자세 그대로 미끄러지는 것이 지금은 정상이다.
     - 맞는 순간이 안 읽힘
     - 효과가 너무 많음·적음
   - **관리 화면**
     - 무엇을 해야 할지 모르겠는 곳
     - 한국어 문장이 어색하거나 잘린 곳
     - 휴대폰 폭(약 400px)에서 깨지는 곳
   - **재미**
     - 지루한 곳
     - 선택이 의미 없어 보이는 곳
     - 전투가 「마구잡이로 붙어서 치고받기만」 하는 느낌이 드는 순간(주인이 짚은 것). 몇 초에 무엇이 그랬는지.
4. 같은 문제는 한 번만 적는다. 문제마다 아래를 적는다.
   - 재현 순서
   - 기대한 것과 실제
   - 스크린샷 경로
   - 심한 정도(막힘 / 거슬림 / 사소함)
