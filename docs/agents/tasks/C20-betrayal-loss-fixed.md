# C20 — 결전 배신과 외부단 손실도 출격 때 고정 (GPT, 코드 일감)

## Why
Codex 의 C18 교차 확인(`docs/agents/reports/codex.md` 「C18」)이 C14 뒤에 남은 틈 두 개를 찾았다.
1. **전투 모드 결전의 외부단 배신이 새로고침 때 바뀔 수 있다.**
   - 위치: `js/contract.js:379`, `:390`, `js/muster.js:204`
   - 같은 출격에서 충성도 12 외부단이 공유 난수 0.01 이면 배신하고, 0.99 면 배신하지 않았다.
   - 전투 모드는 「관전 = 판정, 출격 때 굳힘」이 원칙이다. 그래서 이것이 더 중요하다.
2. **roll 모드 외부단 인원 손실이 다시 굴려진다.**
   - 위치: `js/company.js:277`, `js/contract.js:575`
   - 직속 결과를 고정해도 외부 사상자가 1명/0명으로 바뀐다.

**시작 조건:** 총괄의 「한 부대 초반 다듬기」가 같은 `js/contract.js` 를 고치는 중이다. 그 작업이 게임 브랜치에 들어간 뒤 최신에서 시작한다(`docs/agents/STATUS.md` 확인).

## Do
1. 전투 모드 배신
   - 배신 여부를 출격 때 굳힌 전투 입력(spec)에 넣거나, 출격 시드(`c.bseed`/`rseed` 계열)에서 결정적으로 뽑는다.
   - 굳힌 spec 은 이미 「외부단이 실제로 싸우는지」를 담아야 한다. 관전 전투와 판정이 같아야 하기 때문이다.
   - 예전 공유 난수 소비 자리는 C14 처럼 보존한다.
2. roll 외부단 손실
   - 손실 굴림을 C14 의 `resultRoll`(임무 난수열)에 연결한다.
   - 공유 소비 자리를 보존한다.
3. 시험
   - C18 재현(결전, 충성도 12 외부단, 공유 난수 0.01/0.99)에서 두 모드 모두 결과가 같아야 한다.
   - `node --check`, `node tools/sim/battle.js 100` 은 miss=0 이어야 한다.
   - roll md5 가 바뀌면 이유를 적는다.
   - 전투 모드 봇 요약은 전후 표를 남긴다.
   - `shadow.js 6 365 --resolve battle --check` 는 0 이어야 한다.
