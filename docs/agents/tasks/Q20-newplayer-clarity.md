# Q20 — 처음 하는 사람에게 전투 모드가 설명되는가 (GPT-QA, 보고만)

## Why
전투 모드를 기본으로 바꾸기 전에 확인할 것이 있다. 처음 하는 사람이 다음 세 가지를 게임 안에서 알 수 있어야 한다.
- 다섯 단어(무모·열세·백중·우세·압도)가 무슨 뜻인가
- 지면 어떻게 되는가: 보상 일부, 유예 주간, 부상, 특별 전투에서만 사망
- 왜 졌는가: 시간 초과, 쓰러짐

Q16 에서 「유예 주간 안내를 놓치기 쉽다」, 「일부 보상의 이유가 일관되지 않다」가 나왔다. 이 부분은 총괄이 고치는 중이니 **나머지**를 본다.

## Do (400px, `?resolve=battle`, 새 프로필, 처음 하는 사람처럼)
1. 도움말·메뉴·툴팁·첫 화면 안내를 모두 열어 본다. 위 세 가지가 어디에 어떻게 설명되는지 표로 적는다.
   - 설명이 없는 것
   - 찾기 어려운 것
   - 말이 어려운 것
2. 출정 창·의뢰 카드·보고서의 문구가 서로 같은 말을 쓰는지 본다. 같은 뜻에 다른 말을 쓰는 곳을 적는다.
3. 고칠 안을 제안한다.
   - 어느 화면에 어떤 한두 문장을 넣을지 쓴다. 한국어 문장 그대로 쓴다.
   - 숫자나 % 는 쓰지 않는다. 주인 결정이다.
