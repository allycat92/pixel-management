# Q16 — 전투 모드를 기본으로 바꿔도 되는지 사람 눈으로 보기 (GPT-QA)

## Why
전투 판정 모드에 3단계와 4단계가 들어갔다(중반 보상, 시간 제한 예상, 후반 의뢰판, 「시간이 빠듯함」 안내). 다음 결정은 주인의 몫이다. **새 게임의 기본을 전투 모드로 바꿀지**를 정해야 한다. 그 판단에 쓸 **사람 플레이 감**을 모은다.

## Do
1. 400×800 에서 `?resolve=battle` 새 게임을 시작해 1~120일을 **실제 화면만으로** 진행한다. API 보조는 하지 않는다.
   - 사람처럼 의뢰를 고르고, 모집·장비·시설도 직접 한다.
   - 비교용으로 1280×900 roll 새 게임도 같은 시드로 60일까지 진행한다.
2. 적을 것
   - 의뢰를 고를 때 예상 단어를 믿게 되는가. 놀란 결과(「우세」인데 짐, 「열세」인데 이김)와 그때 느낌.
   - 지는 경험이 어땠는가: 보상 일부, 유예 주간, 회복. 억울했는가, 납득이 갔는가.
   - 돈과 성장 속도: 60~120일이 답답한가. S 등급은 언제 왔는가.
   - 전투를 보는 재미: 연출이 결과와 맞아 보이는가. 「시간이 빠듯함」 안내가 쓸모 있었는가.
   - roll 과 비교한 느낌: 어느 쪽이 더 재미있었는지, 그 이유.
   - 결함(화면·글·오류)은 심각도 순으로 적는다.
3. 마지막에 **「기본을 전투 모드로 바꿔도 되나」에 대한 QA 의견**을 한 문단으로 쓴다.
   - 찬성 / 조건부 / 반대 중 하나와 그 근거
   - 남은 걱정 셋
