# Q2 — 새로 등록한 그림 열 장을 실제 게임에서 보기 (GPT-QA)

## Why
11-27 에 Antigravity 의 그림 열 장이 게임에 등록됐다.
- 손질: 비요른 도끼 날, 카이 시위 손, 해골 병사 찌르기, 오스윈 피격 무릎, 세라핀·그롬·아스텔 준비 자세 높이
- 새 시트: 고블린, 서리 트롤

Codex 의 C5 는 격리 빌드에서 처음 여섯 장만 봤다. 지금 게임 브랜치에서 사람 눈으로 다시 본다.

## Do
1. 게임 브랜치를 받아 `python -m http.server 8000` 을 띄운다. 1280×900 과 400×800 두 폭에서 본다.
2. 각 캐릭터가 나오는 전투를 1배속으로 재생한다.
   - 해당 의뢰는 테스트 저장으로 만들어도 된다.
   - 고블린은 밝은 들판과 어두운 숲 둘 다에서 본다(대비 손질이 대기 중이라 지금 상태를 기록).
   - 서리 트롤은 설원에서 본다.
3. 각각 확인할 것:
   - 그림이 예전 것이 아닌 새 것인가
   - 발이 땅선에 붙는가
   - 칸 밖으로 잘리지 않는가
   - 고친 부분이 보이는가(도끼 날, 시위 손, 무릎, 준비 자세 높이)
   - 맞는 순간이 읽히는가
4. 문제는 캐릭터별로 PASS / FIX / 미확인 으로 적는다. 장면 캡처를 붙인다(각 500KB 이하).
