# C10 — 배율이 다른 시트용 마네킹 가이드 (Codex)

## Why
C9 에서 비요른(`sheet/captain/frostjarl`) 요청서가 막혔다.
- 비요른 시트는 배율 0.1800 으로 등록돼 있다. 원본 그림이 작게 그려져 있어서다.
- 마네킹은 모두 0.1654 기준이다.
- 그래서 `run_request_guides.py` 가 "the mannequin would have to be rescaled first" 로 멈춘다.

**총괄 결정 (11-27): 등록 배율은 바꾸지 않는다.** 바꾸면 이미 통과한 시트의 게임 속 크기가 달라진다. 대신 마네킹 가이드를 그 시트의 원본 크기로 맞춘다.
- 마네킹 크기는 `pose.scale / sheet.scale` 배(비요른: 0.1654/0.18 ≈ 0.919)로 바꾼다.
- 크기를 바꾸는 기준점은 땅선 위 앵커(x=192, y=870)다.
- 마네킹은 그림이 아니라 가이드이므로 「그린 그림은 변형하지 않는다」 원칙에 걸리지 않는다.
- 게임에서의 보폭은 그대로 유지된다. 원본 보폭 × 0.919 × 0.18 ≈ 원본 보폭 × 0.1654 이기 때문이다.

## Do
1. `tools/art/run_request_guides.py` 가 배율이 1% 넘게 다르면 멈추는 대신, 크기를 바꾼 마네킹으로 가이드를 만든다.
   - 대상 파일은 `guide_*`, `size_*` 그림이다.
   - 크기 조정은 최근접 이웃 방식으로 하고, 선 두께는 원래 마네킹과 비슷하게 유지한다.
2. 크기를 바꾼 `pose.json` 을 요청 폴더 안에 쓴다.
   - 관절 좌표, 손 위치, 보폭(`stride`)을 같은 배율로 바꾼다.
   - 바닥 y=870 과 앵커 열 x=192 는 그대로 둔다.
   - 출처 마네킹과 배율을 기록한다.
3. 이 `pose.json` 의 쓰임새를 정리한다.
   - `add_gait.py --pose` 가 이 파일을 받으면, 그 시트의 배율로 변환했을 때 게임 보폭이 다른 경량 시트와 같아야 한다. 이를 dry-run 으로 확인한다.
   - `gait_requests.py` 의 README 와 `--check` 가 이 파일을 마네킹으로 가리키게 한다.
   - SELF-CHECK 명령도 이 파일을 쓰게 한다.
4. 마네킹 사본 거부(`add_gait` 의 마네킹 검사)가 크기를 바꾼 마네킹 사본도 거부하는지 확인한다.
5. 모든 등록 시트의 배율을 마네킹 배율과 비교해 표로 만든다.
   - 1% 넘게 다른 시트를 모두 적는다(예: 서리 트롤 0.18).
6. 비요른 요청서 `run__captain_frostjarl` 을 만든다.
   - C9 의 다섯 가지 점검을 그대로 적용한다. C9 보고서의 비요른 메모(도끼 약 245px, 양손, 앞쪽 금발 두 갈래)를 쓴다.
   - SELF-CHECK 와 `--check` 가 PASS 여야 한다.
