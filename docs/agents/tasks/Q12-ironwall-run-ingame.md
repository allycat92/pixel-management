# Q12 — 브리긴다 중량 이동을 게임에서 보기 (GPT-QA)

## Why
`9b65599` 에서 첫 중량 이동(브리긴다 8프레임, 중량 마네킹 `heavy_base/v1` 위에 그림)을 등록했다. 주인이 기다리던 것이다.
- 헤드(Antigravity)는 통과로 판정했다. 남은 걱정은 게임 1배 크기에서 H3/H7 교차 프레임의 다리 톤과 철퇴 자루의 대비다.
- 클라우드가 본 것: 몇 프레임에서 철퇴 머리가 방패 면 위에 겹친다. 요청서는 「방패 가장자리 옆에서 읽히게」였다.
- 미리보기: `docs/agents/reports/shots/art/2026-11-27_ironwall_run_x4.gif`

## Do
1. 1280×900 과 400×800 에서, 1배속과 저속(가능하면) 둘 다로 본다.
   - 브리긴다가 있는 부대를 출격시켜 전투에서 이동하는 장면을 본다. 테스트 저장으로 만들어도 된다.
2. 확인할 것
   - 무거운 걸음으로 보이는가(날지 않음, 한 발은 늘 땅)
   - 발이 미끄러지지 않는가(걸음과 이동 속도가 맞는가)
   - 대기 → 이동 → 공격으로 넘어갈 때 크기·옷·방패·철퇴가 튀지 않는가
   - 철퇴 머리가 방패 위에 겹칠 때 읽히는가
   - H3/H7 에서 두 다리가 구분되는가
   - 다른 대장의 이동 옆에서 어색하지 않은가. 비교 대상은 바렌(경량 달리기, 이미 등록됨)이다.
3. PASS / FIX 로 적는다. FIX 면 어느 프레임의 무엇인지 적는다. 그림은 그리지 않는다.
