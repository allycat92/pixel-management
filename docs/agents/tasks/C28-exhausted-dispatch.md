# C28 — 모두 탈진한 부대의 파견 버튼 (GPT, 작은 수정)

총괄이 GPT 에게 넘긴 C 일감이다(병목 규칙, `docs/agents/README.md`) — 이 일감에 한해 게임 코드를 고쳐도 된다.

**현상 (전투 모드 기본 전환 검사에서 재현, 11-28):** 집에 있는 부대의 쉬는 단원이 모두 탈진(피로 ≥ 80)이면
- 의뢰 카드는 「보낼 용병단 없음」이라고 하는데 그 카드의 「파견」 버튼은 눌린다.
- 파견 창의 그 부대 줄은 빈 편성으로 계산한 예상 「무모」를 보여 준다.
- 부대를 눌러도 아무도 골라지지 않고 「용병단을 하나 고르세요.」 그대로, 「출격!」은 꺼진 채다. 탈진 단원 칩을 직접 눌러야 넘어간다.

**고칠 것 (`js/ui-tabs.js` 파견 쪽, 필요하면 `js/ui.js`):**
- 카드가 「보낼 용병단 없음」이면 파견 버튼도 꺼지거나, 눌렀을 때 그 이유를 한 줄로 보여 준다 — 둘 중 화면이 더 분명한 쪽. 탈진 단원도 보낼 수 있게 하는 지금 규칙(직접 칩을 누르면 출격 가능)은 유지할지 코드에서 확인하고, 유지한다면 부대 줄에 「모두 탈진 — 단원을 직접 고르면 보낼 수 있음」처럼 적는다.
- 빈 편성으로 「무모」를 계산해 보여 주지 않는다(「—」 또는 탈진 안내).
- roll 모드 화면도 같은 경우를 확인한다.

**검사:** `node --check`, roll md5 `f1712f75dd50877f69a65caf254be083`(SIM_SHADOW=1 도), `node tools/sim/battle.js 100` miss 0. 400×800·1280×900 스크린샷 전/후. 보고는 `docs/agents/reports/gpt-qa.md` C28 절.
