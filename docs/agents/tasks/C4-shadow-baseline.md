# C4-shadow-baseline: 전투 수치 전환 전 기준선 측정

백랑의 08:10 KST까지 대리 요청에 따라 GPT-QA가 배정. 클로드의 0–1단계 작업과 충돌하지 않게 **기존 버전 기준선만** 측정한다. 새 전투 수치·보정·설계는 범위 밖이다.

1. 엔진 측정 기준은 반드시 `3e62ecd0cef7b28e06ec4882282c8e4ff1a1fc24`의 별도 임시 체크아웃으로 고정한다. 이 브랜치에는 결과 보고와 자기 큐 상태만 남긴다.
2. 기준선에서 `node tools/sim/battle.js 200 1`과 `node tools/sim/battle.js 200 101`, `SIM_SEED=1 node tools/sim/bot.js 12 365 all`과 `SIM_SEED=101 node tools/sim/bot.js 12 365 all`을 실행한다(PowerShell은 `$env:SIM_SEED='1'` / `'101'`). 정확한 명령·시작 시드·실제로 사용한 시드 범위·표본 수·볼 수 있는 결과 요약과 오류를 기록한다. 이 수치는 전환 이후 동일 시드 비교용이며 새 목표의 합격 판정이 아니다.
3. 실행 결과에 따르면 구버전에서 보존할 저장/진행 항목을 짧게 제안한다. 쓰지 않은 관측치(예: 의뢰 별 분포)는 구분하고, 새 수치를 추정하지 않는다.
4. `docs/agents/reports/codex.md`에 결과를 남기고 `agent/codex`에서 자기 줄만 REVIEW로 바꾼다. 게임 코드, 테스트 러너, 에셋은 커밋하지 않는다. 원본 브랜치는 건드리지 않는다.
