## 3차 — 주인 지적과 측정 (11-28)

세라핀 로브 이동 8프레임 수정 (sheet_hero_seraphine_run_a/b). 다리, 발 자리, 철퇴, 치맛단 흔들림은 지금 그대로 둔다. 철퇴는 가이드를 잘 따랐고, 단 흔들림은 승인된 마법사와 비슷한 크기다. 고칠 것은 '머리와 윗몸이 프레임마다 늘었다 줄었다 하는 것'과 '뒤로 날리는 천이 박자 없이 튀는 것' 두 가지다. 좌표는 모두 1536x1024 띠, 칸 안 x 기준이다.

1) 머리와 윗몸은 한 덩어리다. 대기(art/inbox/sheet_hero_seraphine.png 1번 자세)에서 머리 꼭대기(두건 위)부터 가슴 붉은 띠 윗선까지를 한 조각으로 보고, 모든 프레임에서 그 길이를 바꾸지 않는다. 대기 기준 숫자: 머리 꼭대기 → 눈 윗선 48px, 눈 윗선 → 가슴 붉은 띠 윗선 101px, 머리 꼭대기 → 붉은 띠 윗선 149px. 허용은 ±2px이다. 두건을 부풀리거나 납작하게 그려서 높이를 맞추지 않는다.

2) 프레임별 목표 줄 (G5~G8은 G1~G4와 같다):
- 머리 꼭대기: 469 / 472 / 465 / 464. 지금 그대로 맞다.
- 눈 윗선: 517 / 520 / 513 / 512. 마네킹 눈 띠 윗선보다 2px 위다.
- 가슴 붉은 띠 윗선: 618 / 621 / 614 / 613.

지금 그림과의 차이 (- = 위로, + = 아래로 옮긴다):
- 눈: G1 -10, G2 -7, G3 -2, G4 +1, G5 +3, G6 +3, G7 0, G8 -6.
- 가슴: G1 -11, G2 -9, G3 0, G4 +5, G5 +8, G6 +8, G7 +3, G8 -7.

G1·G2·G8은 두건이 길게 늘어나고 얼굴과 몸이 내려가 있다(머리 꼭대기 → 눈 58/55/54). G5·G6은 두건이 납작하다(45/45). 가장 대기에 가까운 G3(50 / 99)의 머리·가슴 조각을 복사해서, 각 프레임에서는 위아래로만 옮겨 놓는다. 크기를 바꾸거나 늘이지 않는다. 얼굴 크기와 눈·코·턱 모양도 모든 프레임이 같아야 한다.

3) 같은 자세는 같은 그림이다. G1=G5, G2=G6, G3=G7, G4=G8은 몸통 높이가 같다(다른 점은 어느 다리가 앞이냐뿐). 머리·윗몸 덩어리의 y는 짝끼리 1px 안으로 맞춘다.

4) 뒤로 날리는 천(찢긴 베일 끝, 긴 머리, 붉은 띠의 넓은 뒤 끝)은 4프레임마다 같은 모양으로 돌아온다. 한 걸음마다 같은 흔들림이고, 한 프레임 늦게 매끈하게 움직인다.
- y=620 높이의 베일 뒤 끝 x가 지금은 110/110/85/89/68/75/83/116이다(G1과 G5가 42px 차이, G7→G8에 +33 튐). G1~G4 값을 기준으로 G5~G8을 맞춘다: 짝끼리 6px 안, 이웃 프레임 사이 12px 안.
- 붉은 띠 뒤 끝의 넓이도 프레임마다 크게 바뀌지 않게 한다. 지금은 1344~2312px이다. 평균 ±15% 안, 짝끼리 비슷하게.

5) 바꾸지 않을 것: 발바닥 y=870, 디딘 발끝 x(279→245→212→178), 철퇴 위치·각도·길이, 치마 단의 높이와 흔들림 크기, 색, 외곽선.
