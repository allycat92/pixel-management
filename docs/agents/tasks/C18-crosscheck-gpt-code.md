# C18 — GPT 가 고친 코드 교차 확인 (Codex)

## Why
병목 규칙(주인 결정 11-27)에 따라 GPT 가 Codex 일감을 대신했다. 규칙상 고친 쪽과 확인하는 쪽은 달라야 한다. 대상은 둘이다.
- **C14** (`ce683e4`, agent/gpt-qa, 아직 게임 브랜치에 안 들어감): roll 귀환 판정·부상/사망·배신만 출격 시드로 굳히고 공유 난수 자리를 보존한다.
- **C16** (`ab7e289`, 게임 브랜치에 들어감 `1ecd870`): 출정 창의 「시간이 빠듯함」 한 줄, `Stats.timeRisk`.

## Do
1. 두 커밋의 코드를 읽는다. 다음을 찾는다.
   - 경계 조건: 시드 없는 옛 임무, 모드 전환, 외부 용병단, 결전, 다부대
   - 난수 순서가 몰래 바뀌는 경로
   - 표시가 판정과 어긋나는 곳
2. C14 를 확인한다.
   - Q13 재현을 다시 돌린다(시드 428103, 3일 #15, 복원 시드 17/139/1977).
   - roll 봇 12판×365일을 시드 세트 2개(GPT 가 안 쓴 것, 예: 601·701)로 전후 비교한다.
3. C16 을 확인한다.
   - 줄이 뜨는 조건이 `Stats.timeRisk` 와 맞는가
   - roll·카드·hold·미선택에서 줄이 안 뜨는가
4. 문제마다 파일:줄, 재현, 제안을 적는다. 문제가 없으면 무엇을 봤는지 적는다.

## Do not touch
코드는 고치지 않는다(보고만 한다).
