# C27 — GPT 의 C24 교차 확인 (Codex, 보고만) — 기본 전환 전 마지막 확인

## Why
GPT 가 C24 를 했다(`67218a8`, agent/gpt-qa). 전투 모드에서 전투 뒤 직속 부상과 외부단 귀환 손실을 출격 시드로 고정하는 일이다.
- roll md5 는 그대로이고, 다시 열기 고정은 6/6 이다.
- 그런데 **전투 모드 봇(시드 1~12)이 크게 움직였다.**

| | 전 | 후 |
|---|---|---|
| 365일 금화 | 48k | 123k |
| 실패 (판당) | 62 | 80 |
| 백중 | 49.9% | 44.8% |
| 우세 | 90.1% | 86.6% |
| 재앙 출현 | 176일 | 117일 |

- 24쌍으로 보면 금화는 16판 상승, 8판 하락이다.
- 주인 결정 8 에 따라 이것이 들어가야 기본을 전투 모드로 바꾼다. 그래서 C26 보다 먼저 한다.

## Do
1. **부상 분포가 같은지** 본다. 쓰러진 직속 단원당 부상 확률과 부상 기간 분포, 외부단 패배당 손실 인원을 전후로 비교한다.
   - 비교 묶음은 시드 1·601·701, 각 12판×365일, 전투 모드다.
   - 새 시드 난수열(`Stats.mix(seed, 소금, id)`)이 같은 출격의 단원들끼리 상관되는지 본다. 예: 한 전투에서 모두 다치거나 모두 안 다치는 쏠림.
   - 기대값과 맞는지도 본다.
2. 금화·실패·단어 승률 변화가 분포 차이에서 오는지, 갈래 차이(잡음)인지 가른다.
   - 쌍별 비교를 한다. 가능하면 같은 전투열에서 부상만 바꾼 반사실 비교도 한다.
3. 다시 열기 고정을 독립 재현한다. 대상은 결전 #17, 밀밭 원정 #16 이다.
4. 문제가 있으면 고칠 안을 낸다(코드는 고치지 않는다).
