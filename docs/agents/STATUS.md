## 총괄이 할 핵심 코딩 (보상 조정 작업이 끝나면)
- 시간이 빠듯한 「우세」(Q11: 2명 거점 공략, R 1.139, 시간 초과로 패배) — 예상 단어는 맞추되 출정 창에 「쓰러뜨릴 시간이 빠듯함」 같은 이유를 붙인다. 표시는 Codex/GPT 일감으로.
- **합칠 것:** GPT 의 C14(`ce683e4`, 결과 판정 굴림만 고정 + 공유 난수 자리 보존, 72판 평균 금화 42.5k→40.1k 잡음 안) — 지금 같은 `js/contract.js` 를 고치는 의뢰주 멸망 작업이 끝나면 합친다. roll md5 새 기준이 될 값 `c8e44d30…`(의뢰주 작업과 겹치면 다시 잰다).
- roll 모드 귀환 결과가 귀환 전 저장을 다시 열면 바뀜(Q13 P1, 예전부터) — 출격마다 결과 난수를 하나 고정. 기본값을 전투 모드로 바꾸면 roll 은 되돌리기용이라 우선순위가 낮아진다. 4단계 결정 때 함께.
- 의뢰주가 멸망한 미출격 의뢰도 정리·출격 방어(`deadTarget` 이 의뢰주도 보게). 영웅 이야기 재게시는 살아 있는 의뢰주나 `locals` 로(Q9 P2, 시드 582802 190일 카이).
- 후반 의뢰판의 폭: ★11~14 해금이 재앙 출현에만 묶여 있다. S 등급·날짜·부대 전력과도 연결한다(Q8 P2, 4단계).
- 후반 금화 쓸 곳: 365일 29만~40만(Q8). 4단계에서 보상 하향보다 선택적 소모처를 먼저 본다.
- 예상이 시간 초과를 모른다: 1~2명 부대가 거점 공략에서 90초 시간 초과로 「압도」·「우세」 패배(Q5, Q6 재현 — 시드 582702 150일, 발렌 siege). 예상에 시간 초과 가능성을 넣거나 인원 부족 경고.

## 끝난 일
- **전투 수치 뼈대 0~1단계 (클라우드)**: 게임에 들어감. 결과·화면은 그대로이고 용병 카드에 네 수치. 검증: 재현 400판 불일치 0, 봇 동일, 결정성 0 위반(2,150판), 적 편성이 보내는 인원과 무관(6,013가지). 브라우저에서는 그림자 전투를 끈다(하루 넘기기 지연 방지).
- 클라우드가 쉬는 동안 GPT 가 대리 총괄로 일감을 배정했다(C4 기준선, C5 그림 6종 게임 반영 QA, 고블린·서리 트롤·카토 요청서).
- **마네킹 여섯 세트 팔 다시 + 로브 마네킹 (Antigravity, `ef09ce9`)**: 모두 판정 통과·기술 검사 통과. 로브 확정판 `robe_base/v1`. 이동 마네킹 세 부류(경량·중량·로브)가 다 갖춰졌다.
- **영입 버튼 손질 (C3, Codex)**: 게임에 들어감.
- 클라우드가 사용량 제한으로 쉬는 동안 GPT 가 주인 지시로 전달·확인을 대신했다(00:30~03:10, 보고 `docs/agents/reports/gpt-qa.md`).
- **플레이테스트 오류 12가지 (C2, Codex → 확인 Q1, GPT)**: 게임에 들어감. 12항목 모두 두 화면 폭에서 통과.
- **자동 반복**: 에이전트가 일감을 스스로 기다렸다 이어서 하고, 클라우드는 에이전트 브랜치를 감시한다(`docs/agents/README.md` 「자동 반복」).
- **플레이테스트 한 바퀴 (A1, Antigravity)**: 두 번 주행, 오류 0. 찾은 문제 17가지를 분류해 나눴다 — 자잘한 12가지는 Codex(C2), 전투 뭉침·초기 배치는 전술 작업, 성장 속도(첫 전직이 105일차)는 밸런싱 때, 코드로 그린 고블린·서리 트롤은 그림 대기열.
- **유닛 밀림 고치기 (C1, Codex)**: 게임에 들어감. 서 있는 유닛이 밀리는 비율 20% → 0.04%. GPT 가 따로 검증.

## 최근 결정 (주인)
- 병목이면 GPT 에게 조율·대리를 부탁하고, Codex 일감도 GPT 로 돌릴 수 있다(11-27 오후). Antigravity 는 곧 다시 시작한다.
- 3단계 뒤 두 답(11-27): 전투 모드 60~120일 보상만 조금 올림(S 90~110일 목표) · 「무모」 의뢰는 그대로.
- 관리 조작은 즉시 저장(총괄, 11-27, C11). 배율이 다른 시트는 등록 배율을 두고 마네킹 가이드를 맞춘다(총괄, C10).
- 전투 수치 뼈대의 네 답(11-27): 난이도는 넓게 나오고 플레이어가 고른다(적 세기는 별 등급) · 사망은 거의 없게(보스·최종 결전만) · 「우세」 85~90% 승 · 전술은 피해의 30~50%.
- 마네킹 팔 고침은 중간 작업물째 Antigravity 에게 넘긴다. 외부 도구 agent-sprite-forge 는 쓰지 않는다.
- 전투를 실제 수치(HP·공격력·방어력 등)로 굴려 결과를 정한다 — 뼈대부터. 전술은 잘 맞는 구성에 보상, 출전 경고·고비 자막 없음.
- 클라우드 Claude = 총괄 기획. 에셋·QA·자잘한 수정은 CLI 에이전트, 큰 결정과 핵심 코딩은 클라우드. 밸런싱은 CLI 시험 데이터 기반.
- **그림은 Antigravity 전담**(Aseprite MCP 포함, 도트 애니메이션 헤드). GPT 계통(GPT·Codex)은 시험·버그 수정·QA.
- 전술이 유닛 효율의 30~50% 를 좌우. 진형은 유닛 선호에서 저절로. 예상 보고서는 전술을 뺀 중앙값(부담되면 난이도 표시).
- 이동 부류 셋: 경량·중량·로브. 달리기 발 미끄러짐은 박자만 고침(B안).
