# 총괄 현황판 (클라우드 Claude 가 관리)

에이전트 보고를 모아 정리하는 곳. 주인은 이 파일 하나로 전체 상황을 볼 수 있다. 갱신: 2026-11-26.

## 진행 중
| 줄기 | 누가 | 상태 | 다음 |
|---|---|---|---|
| 유닛 밀림 고치기 (C1) | Codex | 중간 커밋 `f0036eb` (agent/codex) | 끝나면 클라우드가 시험 결과 검토 후 게임에 넣음 |
| 플레이테스트 한 바퀴 (A1) | Antigravity | 시작 전 | 보고가 오면 클라우드가 문제를 분류해 일감으로 나눔 |
| 마네킹 팔 바로잡기 2차 | 클라우드 (도구) → 판정 Antigravity → 재납품 PC | 도구·요청서 고치는 중 | 통과하면 여섯 세트를 헤드 판정 대기로 |
| 중량·로브 이동 마네킹 | PC | 대기열에 있음 | 납품 → 기술 검사 → 헤드 판정 |
| 전술(전열·사기·협동) | 클라우드 (핵심 코딩) | 결정 문서 `docs/plans/tactics/` | 주인 답 3개 대기, 1단계는 답과 무관 |

## 주인 결정을 기다리는 것
1. 전술이 주로 "벌"이어도 되는가, 잘 맞는 조합에 보상을 더 얹는가
2. 출전 화면에 약점 경고를 띄우는가
3. 전투 고비를 자막으로 보여도 되는가
(자세한 내용: `docs/plans/tactics/2026-11-26_tactics_decision.md` 끝)

## 최근 결정 (주인)
- 클라우드 Claude = 총괄 기획. 에셋·QA·자잘한 수정은 CLI 에이전트, 큰 결정과 핵심 코딩은 클라우드. 밸런싱은 CLI 시험 데이터 기반.
- Antigravity = 도트 애니메이션 헤드 (판정, 최종 그림 가능).
- 전술이 유닛 효율의 30~50% 를 좌우. 진형은 유닛 선호에서 저절로. 예상 보고서는 전술을 뺀 중앙값(부담되면 난이도 표시).
- 이동 부류 셋: 경량·중량·로브. 달리기 발 미끄러짐은 박자만 고침(B안).
