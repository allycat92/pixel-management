첫 관문 — 맞는 순간 고르기

무엇을 하나: 마네킹(뼈대) 동작을 게임 크기로 한 번씩 봅니다. 동작이 끝나면 그 동작의 프레임을 늘어놓은 띠에서 무기가 맞은 순간(타격·발사·피격이 일어난 프레임)을 고릅니다.

몇 번은 일부러 바꾼 판(속임 판)이 섞여 있습니다. 박자를 외우지 말고 본 모양으로 고르세요. 다시 보기는 없습니다.

게임 크기 × 확대, 1배속 실제 시간(설계 ms ÷ 1.3), 효과·화면 흔들림·섬광 없음. 시도 번, 매번 순서가 바뀝니다.

준비

맞은 순간은 몇 번 프레임이었나요? (띠를 누르거나 슬라이더·← → 로 넘겨 보고 Enter. 위 그림 = 게임 크기 ×, 띠 = ×)

내 답

결과 JSON (복사해서 모아 주세요)

여러 사람 결과 합치기

각 사람의 결과 JSON 을 아래에 붙여 넣습니다(한 줄에 하나, 또는 이어서). 세트마다 그 세트의 계획대로 판과 속임 판 답이 둘 다 있는 세션만 셉니다(속임 판 답이 없는 세션은 "not counted (no decoy answer)" 로 따로 적고 세지 않음). 통과: 그런 세션 5개 이상, 그중 80 %(5명 중 4명) 이상이 같은 세션에서 두 판을 다 맞힘 — 계획대로 재생한 판에서 맞는 순간 프레임이나 바로 옆 프레임, 속임 판에서 옮긴 쪽 프레임. 5개 미만이면 FAIL (not enough paired sessions). 주인 혼자 5회(매번 다른 순서)도 5명으로 셉니다.

같은 결과(같은 세션)를 여러 번 붙여도 한 번만 셉니다.
