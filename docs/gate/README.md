# 첫 관문 — 맞는 순간 고르기 (동작 프레임 시운전)

마네킹 여섯 세트를 효과 없이 게임 크기로 한 번씩 보여 주고, 무기가 맞은 프레임을 고르게 하는 시험이다.
여섯 세트는 공격 4개(일반 전사·니클라·브리긴다·병과 궁수)와 피격 2개(일반 전사·니클라)다.
몇 번은 맞는 프레임을 옆 프레임과 바꾼 속임 판이 섞여 있다. 박자를 외우지 않고 모양을 보고 골라야 통과한다.

## 하는 법
1. 저장소를 받는다(`git pull`).
2. 루트에서 `python3 -m http.server 8000` 을 띄우고 http://localhost:8000/docs/gate/gate1.html 을 연다. `gate1.html` 을 더블클릭해 바로 열어도 된다.
3. 「시작」을 누르고 시도 12번에 답한다. 2~3분 걸린다.
4. 끝에 나오는 결과 JSON 을 복사해 Claude 에게 붙여 준다.
5. 한 사람이 다섯 번 해도 된다. 매번 순서가 달라 다섯 명으로 센다.

## 통과 기준
- 세트마다 정상 판과 속임 판 답이 둘 다 있는 세션이 5개 이상이어야 한다.
- 그중 80% 이상이 두 가지를 모두 맞혀야 한다.
  - 정상 판에서 맞는 프레임이나 그 바로 옆 프레임을 고른다.
  - 속임 판에서 옮겨진 쪽 프레임을 고른다.
- 통과하지 못한 세트는 PC 가 마네킹을 고친다.
  - 니클라 공격: swing 의 기울기를 줄인다.
  - 병과 궁수: 놓을 때 손이 튀는 폭을 키운다.
