# 화풍 기준 (Style Guide)

게임 「은빛 늑대 길드」의 그림은 모두 이 기준을 따른다. 게임 안의 기존 도트(16×16 유닛, 코드 생성)와 한 화면에 함께 나오므로 **16비트 시절 판타지 JRPG 도트 그림**의 느낌을 유지한다.

## 공통
- **도트 그림**: 픽셀 덩어리가 또렷하게 보일 것. 안티에일리어싱·그라데이션·블러·사진 질감 금지.
- **팔레트**: 초상화 약 32색, 이벤트 그림 약 48색 이내. 채도는 중간, 어두운 톤 위주에 포인트 색 몇 개.
- **외곽선**: 어두운 보라 계열 `#1b1420`, 1픽셀 굵기(축소 후 기준).
- **조명**: 왼쪽 위에서 오는 빛, 명암 2~3단계의 평평한 셀 음영.
- **금지**: 글자, 서명, 워터마크, 테두리 프레임, UI 요소, 실존 인물·실존 브랜드를 닮은 디자인.
- **게임 안 색**: 요청서에 적힌 피부·머리·옷 색(16진수)을 최대한 지킨다. 게임 속 작은 도트와 같은 인물로 보여야 한다.

## 초상화 (portrait)
- 생성 1024×1024 → 게임에서 128×128로 축소해 쓴다. **축소해도 읽히도록 얼굴과 실루엣을 크게**, 잔디테일은 줄인다.
- 가슴 위(bust shot), 몸은 약간 왼쪽을 향한 3/4 각도. 무기나 상징물이 어깨 근처에 보이면 좋다.
- **배경 투명**(PNG 알파). 투명이 안 되면 단색 `#2a2033` 배경 — 후처리에서 지운다.
- 같은 인물을 다시 그릴 때는 앞서 확정한 그림을 참고 이미지로 함께 넣어 얼굴·복장을 유지한다.

## 이벤트 그림 (event)
- 생성 1536×864(16:9) → 게임에서 480×270으로 축소해 쓴다.
- 영화 같은 구도, 멀리서 본 장면 위주. 인물은 작게 여러 명.
- 배경은 꽉 채운다(투명 아님).

## 세계관 메모
- 대륙 에르덴, 중세 판타지. 용병 길드 「은빛 늑대」의 깃발은 **짙은 붉은 바탕에 은빛 늑대 머리**.
- 세력 색: 왕국 파랑, 북부 진청, 자유 도시 청록, 교단 흰색·금색, 엘프 초록, 부족 연합 적갈색, 마물 군단 검붉은색, 마왕군 보라.
