# 공격 마네킹 · `atk__captain_shadowqueen` — 니클라 (X 감기 → 낮은 가위 베기)

공통 규칙은 `art/requests/guides/SPEC.md` (캔버스 3절, 레이어 4절, 관절 점 4절, **10절 = 동작 마네킹의 이름·납품·검사 수치**). 이 파일 하나만 읽고 끝낼 수 있게 적었다. 요청 2026-11-26 (클라우드).
초안은 없다 — **클라우드는 이 세트의 초안을 굽지 않는다**. 대신 **주인이 이미 승인한 니클라 칸**에 맞춰 짓는다(아래 「승인된 칸에 맞추기」).

## 왜 만드나 (주인 결정)
- 전투 동작을 4장면에서 **프레임 시퀀스**로 바꾼다 (`docs/plans/2026-11-26_motion_frames.md`). 니클라는 병과 전사와 함께 **시운전 캐릭터**다(마네킹 → GPT 띠 → 사이 프레임 → 엔진 전부).
- **마네킹 시퀀스는 PC 가 만든다** (주인: "마네킹 시퀀스도 pc하청으로"). 클라우드는 사양과 검사만. 스크립트로 지어도, 걷기·달리기 `.aseprite` 를 몸 틀로 써도 된다.
- **캐릭터마다 자기 방식으로 움직인다** (주인). 니클라의 기본기 「밤의 칼날」 = 두 칼을 머리 위에서 **X 자로 감았다가**, 낮게 숙이며 앞으로 내딛어 **가위처럼 닫아 벤다**. 맞는 순간 = 가위가 닫힌 프레임 **하나**.
  특기 「그림자 난무」(4명)도 판정은 한 틱이라 같은 흐름, 맞는 순간 프레임도 하나다(돌진 잔상이 휘두름 중간을 덮고, 피해자 반응이 50ms 씩 차례로 — 엔진 몫).
- 주인이 승인한 칸을 다시 쓴다(계획 S5): 휴식 = 대기 칸, **준비 멈춤 = X 감기 칸**, **휘두름 중간 = 승인된 낮은 가위 베기 칸**(주인이 "그럴듯한 사이 동작"이라 한 그림). 그래서 이 마네킹의 hold·swing 은 그 칸과 겹쳐야 하고, 나머지 프레임이 그 칸에서 이어져야 한다.

## 관절 목표 (머리 단위 → 원본 px, 머리 110)
- 가로: **x = 0 이 준비(hold)의 뒷발목, x px = 56 + 110·x** (전체가 x=35~347 에 들어간다). 세로: **y px = 870 − 110·h**. 손은 바닥 위 실제 높이.
- 칼 각도: 수학 각도(0° 앞, 90° 위, 180° 뒤, −90° 아래), 손 점에서 칼끝 방향. **가까운 칼이 크게 돈다**: 150°(뒤-위) → 0°(앞) → −25° → −55°, 준비 → 지나침 205°(검사는 한 칼이라도 120° 이상).
  맞는 순간에 두 칼 모두 타격선을 지난다: 가까운 칼은 휘두름 중간 → 맞는 순간 → 지나침에서 계속 시계 방향(0 → −25 → −55), 먼 칼은 계속 반시계(−35 → −8 → +22).
  승인된 X 에서 위-뒤를 가리키는 칼이 먼 손의 것이면 두 레이어의 각도를 맞바꾼다 — 그래도 한 칼은 준비 → 지나침 120° 이상.

## `motion_chars.json` 과 다른 곳 (클라우드가 고친 이유 — 클라우드가 JSON 에 되돌려 넣는다)

## 시작하는 법 (PC 가 고른다)
1. **스크립트(권장)**: `walk8_pc.py` 처럼 `tools/pixelart/posekit.py`(`pk.Body(4.0)`, `pk.build(pose, B, 'none')`) + `tools/pixelart/walk8.py`(`draw`, `frame_layers`, `floor_row`)로 표를 포즈로 넣어 부위 레이어 + `joints` 점을 쓴다.
   포즈 키: `hip=(x, h)`, `lean`, `footN=(x, 0.12)`, `footF=(x, 0.12)`, `handN=('p', x, h)`, `handF=('p', x, h)`, `elbN`/`elbF`, `faN=faF=0`. `frame_layers` 는 x=0 을 192px 에 두므로 모든 x 에서 (192−56)/110 = 1.24 를 빼고 그린다.
   칼 두 자루는 스크립트에서 위 크기로 그린다. 실행 예: `uv run --no-project --with pillow --with numpy python ~/Documents/pm-pc-scratch/mannequin_pc.py . ~/Documents/pm-pc-scratch/atk__captain_shadowqueen`.
   조립은 걷기 v2 때처럼 aseprite-mcp 도구로(프레임 시간·`attack` 태그·`joints` 숨김).
2. **몸 틀**: `art/requests/guides/run_base/v1/run_base.aseprite`(숙인 달리기 몸이 맞는 순간에 가깝다) 또는 `walk_base/v2/walk_base.aseprite` 의 부위 레이어를 옮긴다. 뼈 길이(89.65 / 68.2 / 71.5px)는 바꾸지 않는다.
3. 승인된 칸을 스크래치에서 양파 껍질처럼 겹쳐 맞춘 뒤, Aseprite 에서 **재생해 본다**. X 에서 가위가 "싹" 닫히는 한 프레임이 읽히는지는 PC 만 볼 수 있다.
