## 왜 만드나 (주인 결정)
- 전투 동작을 4장면에서 **프레임 시퀀스**로 바꾼다 (`docs/plans/2026-11-26_motion_frames.md`). 니클라는 병과 전사와 함께 **시운전 캐릭터**다(마네킹 → GPT 띠 → 사이 프레임 → 엔진 전부).
- **마네킹 시퀀스는 PC 가 만든다** (주인: "마네킹 시퀀스도 pc하청으로"). 클라우드는 사양과 검사만. 스크립트로 지어도, 걷기·달리기 `.aseprite` 를 몸 틀로 써도 된다.
- **캐릭터마다 자기 방식으로 움직인다** (주인). 니클라의 기본기 「밤의 칼날」 = 두 칼을 머리 위에서 **X 자로 감았다가**, 낮게 내딛으며 **가위처럼 닫아 벤다**: 위 칼은 머리 위에서 앞-아래로 내려오고, 아래 칼은 밑에서 앞-위로 올라와
  **맞는 순간 두 칼끝이 앞에서 만난다**(가위가 닫힘), 지나침에서 서로 엇갈려 지나간다. 맞는 순간 = 가위가 닫힌 프레임 **하나**.
  특기 「그림자 난무」(4명)도 판정은 한 틱이라 같은 흐름, 맞는 순간 프레임도 하나다(돌진 잔상이 휘두름 중간을 덮고, 피해자 반응이 50ms 씩 차례로 — 엔진 몫).
- 주인이 승인한 칸을 다시 쓴다(계획 S5): 휴식 = 대기 칸, **준비 멈춤 = X 감기 칸**, **휘두름 중간 = 승인된 낮은 가위 베기 칸**(주인이 "그럴듯한 사이 동작"이라 한 그림). 그래서 이 마네킹의 hold·swing 은 그 칸과 겹쳐야 하고, 나머지 프레임이 그 칸에서 이어져야 한다.

### 팔 고침 (2026-11-26, 첫 관문 뒤 — 주인 「팔이 어떻게 꺾이는지 좀 봐봐」, SPEC 10.3b)
첫 납품(`art/inbox/guides/atk__captain_shadowqueen/`)의 팔: 먼 손(위 칼)이 in·swing 에서 제 어깨 위(0.09~0.14머리)라 **접힘**(8°·12°), recover·settle 은 손이 허리로 내려오는데 팔꿈치가 가슴 앞으로 **뒤집힘**, settle 가까운 팔 **닭날개**. hold 의 `elbN [-1, 0.2]` 은 이제 필요 없다(손이 머리 위면 팔꿈치는 저절로 앞).
고친 것: contact·follow 의 먼 손은 **머리 높이로 치켜든 손**(팔꿈치가 손보다 아래, 얼굴 앞) — 목 뒤로 감기지 않게. recover·settle 의 먼 손은 허리 아래 앞으로 내려 팔이 거의 펴진다.
- 마네킹 스크립트는 posekit `natural-arms 1` 로 짓는다 — 포즈에 `"arms": "natural"` (팔꿈치가 해부학 쪽으로만 굽는다). `elbN` / `elbF` 는 아래 표가 남긴 것만 쓴다. 검사기 `--motion` 이 이제 팔꿈치 방향을 재서 닭날개·교차·뒤집힘·반대 꺾임·접힘을 FAIL 로 잡는다.

## `motion_chars.json` 과의 관계
- `chars["sheet/captain/shadowqueen"].mannequin.overrides` 의 hold·swing·contact·follow 는 **이 표와 같은 값**이다(2026-11-26e). JSON 의 x 는 posekit 처럼 대기 엉덩이 열이 0 —
  이 표의 x 에서 0.48 을 뺀 값이다(좁은 대기의 뒷발목이 대기 엉덩이 −0.48, 그 발이 hold 까지 제자리). 손·칼은 at() 단위로 적었다. 예전 값과 다른 곳과 이유:
  - hold 메모 "X behind the shoulders ... feet narrow (25 px at game size)": 승인된 칸 #2 는 X 가 **머리 위**이고 발 폭도 약 1.76 머리(게임 약 32px)다. 게임 25px 는 대기 칸 #1 의 폭이다. 승인된 칸을 따른다.
  - contact 엉덩이 (0.40, 1.08)·기울기 0.30, 두 손 앞-아래 → 이 표의 (+1.42, 1.08)·**0.20**, 위 칼 내려옴 / 아래 칼 올라옴: 검사가 요구하는 준비 → 맞는 순간 머리 이동 100px 이상·엉덩이 55px 이상을
    승인된 X 칸에서 출발해 채우려면 앞발 내딛기(+0.20)가 필요하다. 그리고 몸을 덜 숙여(0.40 → 0.20) 두 손을 몸통 앞으로 뻗어야 두 칼이 칸 안에서 몸 밖에 보인다(숙인 몸통에 칼이 25% / 22% 만 보였다).
  - follow 기울기 0.34 → **0.24**(맞는 순간과 이어지게).
