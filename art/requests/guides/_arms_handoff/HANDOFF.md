# 마네킹 팔 고침 — Antigravity 에게 넘김 (2026-11-26)

주인 결정: "마네킹 관련해서는 중간 작업물을 antigravity 쪽으로 토스". 클라우드가 하던 팔 고침을 여기서 멈추고 넘긴다.
**이제부터 여섯 세트의 마네킹은 Antigravity 가 그림 전담으로서 직접 마무리하고, 통과 여부도 눈으로 판정한다.**

## 무엇이 문제였나
첫 관문 뒤 주인이 말했다: "마네킹 상태가 영 안좋은데. 팔이 어떻게 꺾이는지 좀 봐봐."

납품됐던 여섯 세트(`art/inbox/guides/<세트>/<세트>.aseprite`, 만든 스크립트는 같은 폴더의 `mannequin_pc.py`)에서 팔이 세 가지로 잘못 꺾였다.
1. **닭 날개**: 위팔이 등 뒤로 가고 아래팔이 다시 가슴·배로 접힌다. 전사 공격의 in·settle, 전사 피격 전부, 니클라 피격의 먼 팔.
2. **팔꿈치 들림**: 손은 허리에 있는데 팔꿈치가 가슴 높이에서 앞·밖으로 뜬다. 전사 swing, 니클라 공격의 swing~settle, 니클라 피격 K3·K4.
3. **엇갈림**: 전사 hold 에서 팔이 가슴 앞 V 로 엇갈린다.

원인은 두 가지다.
- 손 자리에서 팔꿈치를 계산하는 도구(posekit)가 팔꿈치 방향을 화면 기준으로 골랐다.
- 요청서 표의 손 자리 자체가 무리였다. 손이 어깨에 너무 가깝거나 몸 뒤에 있었다.

팔 76개를 잰 표는 `diagnosis_arms_table.tsv` 에 있다.

팔이 자연스러우려면 손이 「팔꿈치가 어깨 밑에 늘어진 자리에서 아래팔로 닿는 원」 안에 있어야 한다. 그 밖에 손을 둔 팔 20개는 모두 잘못 꺾였다.

## 클라우드가 해 둔 것 (쓸지 말지는 Antigravity 가 정한다)
- **1차** (`round1_before_after.png`, `round1_scripts/`, `round1_changes.md`)
  - 피격 두 세트와 궁수는 자연스러워졌다.
  - 새 결함이 생겼다. 전사 hold 와 브리긴다 hold~recover 에서 무기 든 팔이 **얼굴을 가로지른다**.
  - 정해 둔 동작도 바뀌었다(둘 다 무기를 머리 뒤로 치켜듦). **이 부분은 쓰지 않는다.**
- **2차 중간본** (`round2_wip/`: 세트별 큰 그림 `sheets/`, 스크립트 `scripts/`, 수치 `margins.txt`·`similarity.txt`)
  - 정해 둔 동작을 되살리고 팔을 다시 풀던 중에 멈췄다.
  - 전사 공격은 눈으로 보기에 꽤 괜찮다. hold 에서 칼 손이 엉덩이 뒤 낮게 있고, 팔이 곧게 내려간다.
  - 나머지 세트는 **검증 전**이다.
- **도구** (저장소에 들어가 있다)
  - `tools/pixelart/posekit.py`: 자세에 `"arms": "natural"` 을 넣으면 팔꿈치를 해부학 쪽으로 고른다.
  - `tools/art/check_skeleton.py --motion`: 닭 날개·들림·엇갈림·얼굴 가림을 잡는다. **검사기는 보조다.** 통과해도 눈에 이상하면 다시 한다. 눈에 자연스러운데 검사기가 잘못 잡으면 NOTES 에 적는다. 그러면 클라우드가 검사기를 고친다.

## 지켜야 할 동작 설계 (캐릭터끼리 달라 보이게 정해 둔 것)
- **병과 전사 공격**
  - hold 에서 칼 손은 **엉덩이 뒤 낮게** 둔다.
  - 휘두름 중간에 방패로 밀친다.
  - 맞는 순간 칼이 **방패 밑으로 낮게** 뻗는다.
  - 방패는 끝까지 가슴 앞에 보인다.
- **브리긴다(아이언월) 공격**
  - 탑방패 뒤에 웅크려 버틴다.
  - 맞는 순간 **몸 전체로 방패를 밀어붙인다**.
  - 철퇴는 **어깨~머리 높이에서 뒤로 겨눈다.** 머리 위로 들지 않는다. 손은 얼굴 옆·뒤에 두고 얼굴을 가리지 않는다.
- **니클라 공격**: 머리 위에서 쌍검을 X 로 감는다 → 낮게 돌진한다 → 팔을 뻗어 가위가 닫히는 순간이 맞는 순간이다 → 엇갈려 지나간다.
- **병과 궁수**: 200ms 당겨 멈췄다가 놓는 순간 시위 손이 뒤로 튄다.
- **피격 (전사·니클라)**
  - 발은 붙인 채 머리·어깨가 뒤로 튀었다 돌아온다.
  - 무릎을 들지 않는다.
  - 전사는 방패를 앞에 남긴다.
- 프레임 수와 시간(ms)은 각 요청서 README(`art/requests/guides/<세트>/README.md`)를 따른다. README 의 「팔 고침」 절 가운데 무기를 머리 뒤로 치켜들라는 1차 문구는 무시한다.

## 할 일
1. 여섯 세트를 Aseprite 로 마무리한다. 2차 중간본 스크립트에서 시작해도 되고, 납품본을 직접 고쳐도 된다.
2. 프레임을 크게 보고, 게임 크기·게임 속도로도 본다. 볼 것:
   - 어느 팔도 닭 날개·들림·엇갈림이 없다.
   - 팔이 얼굴을 가리지 않는다.
   - 방패·무기가 숨지 않는다.
   - 어깨가 튀지 않는다.
3. 자체 검사를 돌린다. 공격 세트 예:
   `python tools/art/check_skeleton.py <파일.aseprite> --motion attack --set atk__class_warrior`
   피격은 `--motion hit` 로 바꾼다.
4. 납품한다. `art-inbox` 의 `art/inbox/guides/<세트>/<세트>.aseprite` 에 같은 이름으로 다시 올린다. NOTES 에 「판정 — id」 절을 적는다.
5. 여섯 세트가 통과하면 클라우드가 첫 관문 페이지를 다시 만든다.
