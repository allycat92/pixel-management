# 피격 마네킹 · `hit__class_warrior` — 일반 병과 전사 (보통 무게: 방패 뒤로 움찔)

공통 규칙은 `art/requests/guides/SPEC.md` (캔버스 3절, 레이어 4절, 관절 점 4절, **10절 = 동작 마네킹의 이름·납품·검사 수치**). 이 파일 하나만 읽고 끝낼 수 있게 적었다 — **묻지 않고 끝까지 한다**. 요청 2026-11-26 (클라우드), 고침 2026-11-26e.
초안은 없다 — **클라우드는 이 세트의 초안을 굽지 않는다**. 대신 K1·K2 의 관절값은 이미 정해져 있다(`tools/pixelart/posekit.py` `HIT_KEYS` 의 `k1_mid`, `k2_mid`).

## 왜 만드나 (주인 결정)
- 지금 피격 칸은 표정이 그대로이고, 앞발을 높이 들고, 몸을 크게 젖혀 우스꽝스럽다. 주인 결정: **그럴듯한 움찔** — 머리와 어깨가 맞은 쪽 반대로 밀렸다가 돌아오고, 무릎이 굽어 충격을 받고,
  **두 발은 바닥에 그대로**, 무기는 쥔 채, 무거운 캐릭터일수록 덜 흔들린다(계획 1절·5절). 무게(무거움·보통·가벼움)마다 K1(맞음)·K2(가장 깊은 점) 두 키를 둔다.
- **마네킹 시퀀스는 PC 가 만든다** (주인: "마네킹 시퀀스도 pc하청으로"). 클라우드는 사양과 검사만.
- **캐릭터마다 자기 방식으로 움직인다** (주인). 전사는 보통 무게이고 면갑으로 얼굴이 가려져 있어 **실루엣만으로** 읽혀야 한다: 머리가 방패 뒤로 숙고 어깨가 밀렸다 돌아온다.
  가벼운 니클라(`hit__captain_shadowqueen`)와 같은 프레임이 되면 안 된다.

## 납품 (모든 마네킹 세트가 지키는 약속)
- art-inbox **`art/inbox/guides/hit__class_warrior/hit__class_warrior.aseprite` 하나**. 띠·프레임 PNG·GIF 는 올리지 않는다(클라우드가 뽑는다). 스크립트를 썼으면 같은 폴더에 `mannequin_pc.py`(수령 도구가 납품과 함께 받는다).

- 레이어(아래 → 위): `Background` · `arm_far` · `shield` · `leg_far` · `leg_near` · `torso` · `head` · `weapon_front` · `arm_near` · `joints`(숨김). 소품은 공격 세트(`atk__class_warrior`)와 같다:
  칼(가까운 손, 손 점에서 칼끝 0.85 머리, 손잡이 0.22 뒤), 둥근 방패(먼 팔, 0.68 x 0.90 머리 타원). 이 밖의 이름은 FAIL, 숨김은 `joints` 하나.
- **프레임 4개, 표 순서대로, 프레임 시간 = 표의 ms**. 태그 `hit` 하나가 1~4 전체(프레임별 태그는 표의 이름 그대로만 — `K1 impact` 처럼 공백 포함).
- **세계 좌표, 두 발은 4프레임 내내 그 자리**: 앞발(`leg_far`)과 뒷발(`leg_near`) 모두 ±3px, 발바닥 평평히 y=870(발목 높이 ±3px — 발목을 3px 넘게 올리는 뒤꿈치·발끝 들기는 FAIL). 그림 전체 x=32~351 안.
- **K3·K4 는 마네킹에서 빼지 않는다**: 최종 그림에서 "뺄 수 있는(droppable)" 프레임이지만, 마네킹은 4프레임 모두 있어야 검사가 돈다(프레임 수가 다르면 FAIL).

## 이 캐릭터만의 것 (가벼운 니클라와 다른 점)
- 보통 무게: 머리 밀림 32 → 46px(니클라 50 → 70), 발은 하나도 안 움직인다(니클라는 K2 에서 뒷발이 33px 물러나는 휘청 한 걸음).
- **방패가 앞에 남는다**: 몸이 밀려도 방패 손은 0.1~0.2 머리만 물러나고 머리가 그 뒤로 숙는다 — 실루엣에서 "방패 뒤로 움츠림"이 읽혀야 한다(면갑이라 표정은 안 보인다).
- 칼 든 팔은 K2 에서 균형을 잡으려 뒤로 조금 벌어진다(무기는 놓지 않는다). 니클라는 두 칼을 아래로 쥔 채 어깨가 비틀린다.
- 넓은 발(−0.90 / +0.80) — 니클라는 좁은 대기(두 발 바깥 폭 게임 25px).

## 시작하는 법 (PC 가 고른다)
1. **스크립트(권장)**: `tools/pixelart/posekit.py` 를 불러 `pk.HIT_KEYS['k1_mid']`, `pk.HIT_KEYS['k2_mid']` 를 그대로 쓰고(발만 이 세트의 −0.90 / +0.80 으로),
   `pk.build(pose, B, 'none')` + `tools/pixelart/walk8.py`(`draw`, `frame_layers`, `floor_row`)로 부위 레이어 + `joints` 점을 쓴다. 포즈 키: `hip`, `lean`, `tilt`, `head_off`, `footN=(−0.90, 0.12)`, `footF=(0.80, 0.12)`,
   `handN=('p', x, h)`, `handF=('p', x, h)`, `faN=faF=0`(발 각도 없음 — 가장 안전하다. 검사는 발 각도가 아니라 **발목**을 본다: 뒤꿈치를 들어 발목이 대기 높이에서 3px 넘게 움직이면 FAIL. posekit 시험(K2 뒷발, 전사·니클라 같음): `faN=12`·`13` 은 통과, `faN=14`·`15` 는 발목 +4px 로 FAIL. 뒤꿈치를 들 때는 발끝을 선 자리에 그대로 둔다). `frame_layers` 가 x=0 을 192px 에 두므로 그대로 쓰면 된다. 칼·방패는 스크립트에서 그린다.
   K1·K2 의 생김새를 미리 보려면: `uv run --no-project --with pillow --with numpy python tools/art/handoff.py --hit-set ~/Documents/pm-pc-scratch/hit_set`
   → `~/Documents/pm-pc-scratch/hit_set/sword_shield/guide_hit_k1_mid.png`, `guide_hit_k2_mid.png`, `hit_overview.png`(posekit 몸, 원래 넓은 발). 참고만 — 납품에 넣지 않는다.
   실행 예: `uv run --no-project --with pillow --with numpy python ~/Documents/pm-pc-scratch/mannequin_pc.py . ~/Documents/pm-pc-scratch/hit__class_warrior`. 조립은 걷기 v2 때처럼 aseprite-mcp 도구로(프레임 시간·`hit` 태그·`joints` 숨김).
2. **몸 틀**: `art/requests/guides/walk_base/v2/walk_base.aseprite` 의 부위 레이어를 옮긴다. 뼈 길이(89.65 / 68.2 / 71.5px)는 바꾸지 않는다.
3. Aseprite 에서 **재생해 본다**(70·100·80·70ms). "맞아서 움찔했다가 돌아온다"로 읽히는지, 무릎이 들리거나 몸이 젖혀져 보이지 않는지.
