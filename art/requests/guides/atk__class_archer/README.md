# 공격 마네킹 · `atk__class_archer` — 일반 병과 궁수 (당기기 → 놓기)

공통 규칙은 `art/requests/guides/SPEC.md` (캔버스 3절, 레이어 4절, 관절 점 4절, 활 예외 8절, **10절 = 동작 마네킹의 이름·납품·검사 수치**). 이 파일 하나만 읽고 끝낼 수 있게 적었다. 요청 2026-11-26 (클라우드).
초안은 없다 — **클라우드는 이 세트의 초안을 굽지 않는다**. **이 세트는 마네킹만**이다(시운전에서 GPT 띠를 내지 않는다).

## 왜 만드나 (주인 결정)
- 전투 동작을 4장면에서 **프레임 시퀀스**로 바꾼다 (`docs/plans/2026-11-26_motion_frames.md`). 활의 한 흐름 = 화살 메기기 → 들어 올리기 → 당겨 멈춤 → **놓기** → 지나침 → 내리기 → 자리 잡기.
- **마네킹 시퀀스는 PC 가 만든다** (주인: "마네킹 시퀀스도 pc하청으로"). 클라우드는 사양과 검사만. 스크립트로 지어도, 걷기·달리기 `.aseprite` 를 몸 틀로 써도 된다.
- **캐릭터마다 자기 방식으로 움직인다** (주인). 이 세트는 활의 기준이다 — 나중의 궁수들(카이: 귀까지 길게, 나린: 짧게 튕김, 세레니엘: 부드럽게…)은 이것과 달라야 한다.
- 첫 관문에 넣는 이유(계획 0절): 활의 **놓기**는 모든 공격 중 가장 약하게 읽히는 맞는 순간이고(몸은 거의 그대로, 손만 튄다), 병과 궁수는 예산이 가장 빠듯하다(대륙 순찰자 질풍 사격 0.6초 → 510ms, 줄어드는 프레임으로만 들어감).
  놓기가 게임 크기에서 읽히는지, 화살이 나가는 자리(원점)가 표시되는지를 본다.

## 납품 (모든 마네킹 세트가 지키는 약속)
- art-inbox **`art/inbox/guides/atk__class_archer/atk__class_archer.aseprite` 하나**. 띠·프레임 PNG·GIF 는 올리지 않는다(클라우드가 뽑는다). 스크립트를 썼으면 같은 폴더에 `mannequin_pc.py`.
- 한 프레임 384x1024, Background #FF00FF, 바닥 y=870, 머리 110px, 오른쪽을 본다.
- 레이어(아래 → 위, SPEC 4절 순서): `Background` · `arm_far` · `leg_far` · `leg_near` · `torso` · `head` · `weapon_front` · `arm_near` · `joints`(숨김).
  활·시위·화살은 모두 `weapon_front` 한 레이어(활은 **먼 손**이 쥔다, 시위는 가까운 손이 당긴다). 이 밖의 이름은 FAIL, 숨김은 `joints` 하나.
- **프레임 7개, 표 순서대로 한 Aseprite 프레임씩, 프레임 시간 = 표의 ms**. 태그 `attack` 하나가 1~7 전체(프레임별 태그는 표의 이름 그대로만).
- **세계 좌표**: 같은 바닥, **두 발 모두 7프레임 내내 같은 자리 ±3px, 바닥에 평평히**(꼿꼿이 선 궁수). 그림 전체 x=32~351 안.
- **원점(화살이 나가는 자리) = 먼 손끝 점**(`joints` 의 #0000AA, 활 쥔 손 = 화살 받침). 따로 표시 레이어를 만들지 않는다. 놓기 프레임에서 이 점이 화살 받침 위에 있어야 한다.
- 무기 소품(납작한 단색, 캐릭터 그림 아님):
  - 짧은 리커브 활: 높이 1.50 머리(165px), 두께 0.06(7px), 위아래 끝이 궁수 반대쪽으로 살짝 휜 곡선. 먼 손 점이 활 가운데(손잡이). 예 #8A5A2B.
  - 시위: 2~3px 선(예 #E6E6E6, 순백 #FFFFFF 는 쓰지 않는다). 당길 때는 활 두 끝 → 가까운 손 점, 놓은 뒤에는 활 두 끝을 잇는 곧은 선.
  - 화살: 1.15 머리(126px), 4px 선(예 #B0B0B8), 메기기·들어 올리기·당겨 멈춤에만(놓기부터는 없다 — 발사체가 된다). 당겨 멈춤에서 화살촉이 활보다 0.15 머리 앞.
  - 시위·화살은 **가까운 손에 닿는 프레임이 메기기·들어 올리기·당겨 멈춤 셋뿐**이어야 한다(검사가 활 쥔 손을 "레이어에 가장 가까운 손"으로 찾는다 — 지나침에서 손을 시위에서 뗀다).

1.25초로 쏘는 보통 궁수는 줄이지 않고 다 본다. 피격 무게는 가벼움(이번 요청에는 궁수 피격 세트 없음).

## 이 캐릭터만의 것
- 병과 궁수 = 평범한 기준: 꼿꼿이, 볼까지, 짧은 멈춤 뒤 시위 손이 크게 튐. 후드·천 마스크(이 세트에서는 그리지 않음).
- 같은 시트를 노궁 대장(관통 노궁)도 쓴다 — 그래도 활로 그린다(`motion_chars.json` explain).
- 나중의 궁수와 다르게 남길 것: 당김 길이 127px(볼), 몸 기울기 ±3° 안, 활 높이 1.50 머리. 카이는 귀까지·위로 기울여, 나린은 짧게, 테무르는 쏘고 한 걸음 뒤.

## 시작하는 법 (PC 가 고른다)
1. **스크립트(권장)**: `walk8_pc.py` 처럼 `tools/pixelart/posekit.py`(`pk.Body(4.0)`, `pk.build(pose, B, 'none')`) + `tools/pixelart/walk8.py`(`draw`, `frame_layers`, `floor_row`)로 표를 포즈로 넣어 부위 레이어 + `joints` 점을 쓴다.
   포즈 키: `hip=(x, h)`, `lean`, `footN=(−0.85, 0.12)`, `footF=(0.85, 0.12)`, `handN=('p', x, h)`, `handF=('p', x, h)`, `faN=faF=0`. `frame_layers` 는 x=0 을 192px 에 두므로 모든 x 에서 (192−172)/110 = 0.18 을 빼고 그린다.
   활·시위·화살은 스크립트에서 위 크기로(posekit 에도 `bow` 가 있지만 높이 1.9 머리라 줄여서). 실행 예: `uv run --no-project --with pillow --with numpy python ~/Documents/pm-pc-scratch/mannequin_pc.py . ~/Documents/pm-pc-scratch/atk__class_archer`.
   조립은 걷기 v2 때처럼 aseprite-mcp 도구로(프레임 시간·`attack` 태그·`joints` 숨김).
2. **몸 틀**: `art/requests/guides/walk_base/v2/walk_base.aseprite` 의 부위 레이어(꼿꼿한 몸)를 옮긴다. 뼈 길이(89.65 / 68.2 / 71.5px)는 바꾸지 않는다.
3. Aseprite 에서 **재생해 본다**. 60ms 놓기 한 프레임에서 손이 "탁" 튀는 것이 읽히는지는 PC 만 볼 수 있다.
