아래 초안은 클라우드가 수치표로 구운 **출발점**이다 — 이 파일 하나만 읽고 일할 수 있게 적었다.

## 초안 (이 폴더 `v1/`, 클라우드가 `python3 tools/pixelart/run8.py art/requests/guides/run_base/v1 --aseprite tools/art/ase_headless.sh` 로 만든 것)

  걷기 뼈대와 같은 마네킹·같은 캔버스·같은 바닥 줄(y=870)·같은 관절 점 색이다. 열어서 바로 재생·양파 껍질 보기가 된다.
- `v1/run_base_a.png` (R1~R4) · `v1/run_base_b.png` (R5~R8) · `v1/run_base_preview.gif` (게임 크기, 80ms) · `v1/run_base_review.png` (띠 축소 + 전장 바닥색 위 게임 크기 8프레임)
  · `v1/pose.json` (프레임별 관절 좌표·수치, `"gait": "run"`, 요청값 `step_px` 275) · `v1/layers/R<n>_<레이어>.png`

  R4 뜸(**두 발 모두 공중**, 엉덩이 가장 높음, 다리 가위) · R5~R8 같은 것을 먼 발로. **한 번에 한 발만 디딘다.** (아래 수치는 이 `v1/` 초안의 기록이다 — 지금 `run8.py` 를 다시 구우면 `v2/` 가 나온다)

## PC(Aseprite)가 할 일 — 초안을 출발점으로 마네킹 시퀀스를 완성하기
1. 초안을 납품 폴더로 복사한다: `v1/run_base.aseprite` → `../pixel-management-inbox/art/inbox/guides/run_base/run_base.aseprite`.
   Aseprite 로 열고 **재생해 본다**(80ms, 양파 껍질 보기). 띠 PNG 를 잘라 프레임을 만들 필요가 없다 — 이미 프레임·레이어가 나뉘어 있다.
   (클라우드는 정지 그림만 보고 수치를 맞췄다. 재생했을 때 **무게가 실린 달리기**로 보이는지는 PC 만 볼 수 있다 — 깡충거리는 걷기처럼 보이면 안 된다.)
2. 어색한 곳을 손으로 고친다. 클라우드와 검증자들이 잰 다듬을 곳:
   - **R2·R6(내려앉음) 정강이**: 디딘 정강이가 평평한 발 위로 33.9°(R6 은 38.9°)나 앞으로 기울어 발목이 꺾여 보이고, 게임 크기에서 두 다리가 한 덩어리로 뭉쳐 웅크린 자세처럼 읽힌다.
     R2 와 R6 의 상체(두 팔이 엇갈리는 모습)도 거의 같다.
   - **R1·R5(닿음) 내딛기**: 닿는 발이 평평하고 가슴 바로 아래라 "앞으로 내딛는" 느낌이 약하다. 뒤로 접힌 장화가 가로 막대처럼 튀어나온다.
   - **R4·R8(뜸) 앞다리**: 앞다리 정강이가 거의 수직(-8.9° / -1.3°)이고 발이 평평해, 뜸이 "높이 든 닿음"처럼 보인다. 앞다리가 다음 디딤으로 뻗어야 한다.
   - **먼 팔**: 앞으로 갈 때 아래팔만 가슴 앞으로 나온다(프레임 폭 384px 때문에 줄였다 — 그림은 x=32~351 안). 가까운 손은 어깨보다 101px 앞까지, 먼 손은 71px 까지라
     R3·R4 와 R7·R8 의 실루엣이 다르다. 팔꿈치를 더 접는 등 폭 안에서 두 쪽을 가깝게 맞춘다.
3. SPEC 3절(캔버스)·4절(레이어)·5b절(달리기 수치)을 지킨다. 뼈 길이는 바꾸지 않는다. **팔다리를 옮기면 `joints` 레이어의 그 관절 점도 같은 만큼 옮긴다**
   (점 색·크기는 SPEC 4절. 레이어 이름·순서·캔버스 크기·프레임 수·프레임 시간 80ms 는 그대로, `joints` 레이어는 **숨긴 채** 저장). 검사가 실패로 잡는 것:
   - R1~R3·R5~R7 의 디딘 발은 y=870 에서 떼지 않고, 그 프레임의 반대 발은 바닥에 대지 않는다(12px 이상 띄움).
   - R4·R8 은 아무것도 바닥에 닿지 않는다(맨 아래 픽셀이 y=852 보다 아래로 내려오지 않게 — 바닥 틈 18px 이상. 초안은 37~41px).
     막 밀어낸 다리(R4 가까운 쪽, R8 먼 쪽)의 발목은 다른 발목보다 110px 이상 뒤에 둔다.
   - 디딘 발의 **발끝**은 R1 → R2 → R3 에서 프레임마다 같은 거리(약 69px, ±3)씩 뒤로 간다. 발을 옮기면 세 프레임을 같이 본다(발 미끄럼).
     한 걸음(= 2 x (R1 발끝 − R3 발끝))은 275px ±14 — 이보다 크게 바꾸려면 먼저 묻는다(요청을 새로 낸다).
   - 엉덩이 중심(두 엉덩이 점의 가운데)은 모든 프레임에서 x=192 (±1). 몸은 제자리이고 발이 움직인다(시트에 붙일 때 이 열로 맞춘다).
   - `head` 레이어는 `torso` 에 닿아 있어야 한다. 머리는 목을 축으로 기울여도 되지만 목 점에 대해 4px 넘게 밀리면 경고(쪼는 것처럼 보인다).
   - 밀어냄·뜸에서 미는 다리 쪽 팔이 앞, 반대 팔이 뒤(거꾸로면 실패, 60px 미만이면 경고).
   - 그림은 프레임의 x=32~351 안에 둔다(띠 가장자리에 마젠타 32px 가 남아야 한다).
4. 자체 검사(이 저장소 폴더에서, 한 줄 — Aseprite 는 설정의 `ASEPRITE_PATH` 로 도구가 스스로 부른다):
   `uv run --no-project --with pillow --with numpy python tools/art/check_skeleton.py ../pixel-management-inbox/art/inbox/guides/run_base/run_base.aseprite --pose art/requests/guides/run_base/v1/pose.json --base art/requests/guides/run_base/v1/run_base.aseprite`
   — 첫 줄이 `# skeleton run_base (run)` 이어야 한다(달리기 규칙으로 잰다는 뜻). `FAIL` 이 있으면 푸시하지 않는다. `changed against the draft` 줄들과 `RESULT` 줄을 NOTES 에 옮겨 적는다.
   띠 검사(`check_delivery.py --flight-slots 4`)는 이 명령 안에 들어 있다 — `check_delivery.py` 를 따로 돌리지 않는다.
   (초안을 그대로 재면 `RESULT: PASS`, 모든 프레임 `unchanged` 가 나온다.)
5. 납품: art-inbox `art/inbox/guides/run_base/run_base.aseprite` **하나**(띠·GIF 는 클라우드가 이 파일에서 뽑는다). `art/inbox/` 밖은 건드리지 않는다.
   NOTES 절 「뼈대 — 달리기 v1 (Aseprite)」: 바꾼 프레임과 수치(px), 참고한 자료, 검사 줄, 지침 판. 커밋 `Touch up guide run_base (Aseprite)`.
   손댈 곳이 없다고 판단하면 그렇게 적고 초안 `.aseprite` 를 그대로 올려도 된다.

## 참고
- 주인이 준 동작 예시에서 읽은 것(`../attack_notes.md`, `../walk_base/README.md`): 달리기는 상체 기울임·두 발이 뜨는 프레임·오르내림 약 9%.
- 참고 자료(`art/refs/`)는 리듬만 본다. 따라 그리지 않는다.
- 검증자 메모(2026-11-26): 초안은 달리기로 읽힌다(한 번에 한 발, 8프레임 중 2프레임 뜸, R1→R2 디딘 발목 미끄럼 0.0px, 무릎·팔꿈치가 거꾸로 꺾인 곳 없음, 머리 쪼임 없음).
  다만 모두 정지 그림으로만 판단했다 — 재생해서 본 사람이 없다.
- 이 뼈대는 그림을 그릴 때 따라 그리는 가이드다. 게임 프레임으로 등록되지 않는다(`add_gait.py` 가 `guides/` 경로·`joints` 레이어가 있는 파일을 거부한다).
- 엔진: 달리기 프레임이 있는 시트는 `anims.run` + `runStride`(게임 px, 이 초안 45.5)로 등록한다 — SPEC 9절. 엔진은 그려진 칸을 코드 달리기와 같은 박자로 넘기므로
  그림의 보폭이 땅 위 이동보다 길어도 된다(게임 크기에서 발이 조금 미끄러지는 것은 예상된 것) — 발 미끄럼을 줄이려고 걸음을 줄이지 않는다.
- 수치표는 `tools/pixelart/run8.py` 맨 위에 있다. 받은 다듬기는 걷기 때처럼 이 표에 되돌려 넣는다.
