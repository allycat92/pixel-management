# 참고 자료 (`art/refs/`)

동작·화풍을 **참고만** 하는 자료를 둔다. 그대로 따라 그리거나 잘라 쓰지 않는다.

- `art/refs/` 바로 아래(git 에 올라가지 않음): 남이 그린 도트·그림 등 저작권이 있는 자료. 주인의 PC 에만 두고 PC 세션이 읽는다.
- `art/refs/free/`(git 에 올림): 저작권이 끝났거나(예: 머이브리지 연속 사진) CC0 인 자료만. 파일 옆에 `<파일>.source.txt` 로 출처·라이선스를 적는다.

쓰임: 뼈대(`art/requests/guides/`)의 동작 리듬·무게 이동 참고. 비율은 따르지 않는다 — 우리는 4등신, 머리 110px.
동작마다 한 장보다 한 바퀴(4~8프레임) 전체가 좋다: 발 닿음 → 지나감 → 발 듦 순간이 보여야 한다.
