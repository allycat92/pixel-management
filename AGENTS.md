# Notes for coding agents (Codex, Claude, ...)

- Game: vanilla HTML/CSS/JS. Open `index.html` via any static server (`python3 -m http.server`).
- Art workflow: see `art/README.md` (image agents draw and push PNGs to the `art-inbox` branch;
  `tools/art/process.py` converts portraits/events/backgrounds into `assets/art/`).
- Battle character sheets: `python3 tools/art/sheets.py` turns `art/inbox/sheet_*.png` (1x4 key-pose strip,
  2x2 grid, or one full-body pose on flat #FF00FF) into an 80x80-cell sheet (body ~64px, feet at 40,76,
  breathing idle via sprite-gen; GPT captain strips: one file at a time with `--scale 0.1654 --cell 96`, lancer `--cell 112`,
  never the `*_mounted` preview; class / first-batch monster requests carry `scale`, `cell`, `layout` and class key colours
  `tint` in `phase3.json`, which `sheets.py` applies itself) and registers it with `tools/art/register_sheet.py` as `sheet/<kind>/<key>`
  in `assets/art/manifest.json`. Requests: `art/requests/phase3.md` (generated by `node tools/art/requests.js`).
  `process.py` never drops manifest entries it did not produce.
- Sprite post-processing: `.claude/skills/sprite-gen/SKILL.md` — vendored `tools/sprite-gen`,
  **offline commands only**; no sprite-gen generation / server / rife / face-bake commands, no API keys there.
- NovelAI: `tools/art/novelai.py` may generate images **only when the user asks**, within the free tier
  (area <= 1024x1024, <= 28 steps, 1 image per call, `--max` 2 per run; no `--allow-paid` unless the user says so).
  The token is injected by the cloud proxy (or `NOVELAI_TOKEN` locally); never write it to files or logs.
  **NovelAI is for design drafts ONLY (owner decision): final game art always goes through GPT.** Never request or
  register a NovelAI "final": `novelai.py` writes only `art/concepts/<id>/drafts/nai_*.png` (git-ignored) or a scratch
  `--outdir` and refuses `art/inbox/`, `assets/`, `art/requests/`; `sheets.py` refuses NovelAI images
  (`--allow-draft` is a test flag that always implies `--dry-run`).
- GPT handoff (battle sprites): `python3 tools/art/handoff.py` builds `art/requests/phase3/<id>/` (concept, posekit guides,
  `guide_strip.png` layout, README with the GPT prompt); rules in `art/requests/gpt_handoff_notes.md`, messages in `art/requests/phase3_gpt.md`.
- Procedural pixel characters: `tools/pixelart/` (`python3 tools/pixelart/baren.py OUT_DIR`).
- Aseprite: never commit Aseprite binaries (EULA forbids redistribution). Build notes only.
